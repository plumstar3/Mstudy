# 段階22: 期間の重要度(開花後のどの期間の水分の動きが効くか)

- 日付: 2026-11-10(EXP-031)
- 目的:
  - 主の設定 M_diff(label_muniyear_median の123件、開花起点 0〜+59 日の1次差分 → MiniRocket → RidgeClassifierCV、全体 AUC 0.607)で、開花後のどの期間の土壌水分の動きが、多収・低収の分類に効いているかを調べる。
  - 方法: 60日の窓の中の短い部分窓(各20日)だけで学習と評価をやり直し、「その期間だけでどれだけ当てられるか」を比べる。
- 仮説の材料: 大豆は莢伸長期〜子実肥大期(R3〜R6)の水分ストレスが収量に効きやすいとされる。**出典はプロジェクトの調査資料(AI が作った二次資料)で、一次文献では未確認**。
- 試した回数: 期間を分けた評価は今回が初めて(主の設定は変えていない)。

**スクリプト**: `analysis/stage22/run_stage22.py`(引数 `--n-seeds` 10、`--n-perm` 1000)
- 全体で536秒(28並列)。試運転は `--n-seeds 1 --n-perm 20`(65秒)。
- 段階13・14・16の部品を import して使った。60日全体は段階13の `outputs/stage13/` を使う。

**出力**: `rocket/outputs/stage22/`(Git 管理外)

| ファイル | 内容 |

| `run_log.txt` | 実行ログ |
| `summary.csv` | P1〜P5 と60日全体の全体 AUC・bacc・W・B・X、乱数の最小・最大、帰無分布の平均・95%点、p(補正前・Holm 補正後)、特徴量の数、dilation、alpha の張り付き |

## 設定

- データ・分割・モデル・置換は段階13の median・M と同じ。
  - 123件(多収64 / 低収59)、`make_splits(y, muniCd, 5, 20, 0)`。
  - MiniRocket(num_kernels=10000、乱数0〜9)→ StandardScaler(with_mean=False)→ RidgeClassifierCV(logspace(−3, 3, 10) × n_train)。
  - 置換は市町村×年の中でラベルを並べ替え、各窓1000回(置換 i の乱数は [0, i])。まとめて解く(`run_stage6_local._batched_ridge`)。
- **部分窓(事前に固定、各20日)**: 部分窓ごとに生の VWC 20点を切り出してから1次差分(19点)を取った。

| 部分窓 | 開花後の日 |
|---|---|
| P1 | 0〜19 |
| P2 | 10〜29 |
| P3 | 20〜39 |
| P4 | 30〜49 |
| P5 | 40〜59 |

- 比較の基準: 60日全体(M_diff、段階13の結果)。

**短い系列での MiniRocket**
- 19点の入力でもエラーにならず、特徴量は 9,996 で60日と同じ(止めて報告する条件には当たらない)。
- ただし **dilation は {1, 2} だけ**(60日では 1〜7)。部分窓では、カーネル(長さ9)が見る範囲は最大17日で、60日全体のように長い間隔の変化(dilation 7 で最大57日)は見ない。特徴量の数は同じでも中身は違う。

**開始時の確認(すべて True)**
1. 件数(123件)と、分割の表が段階13の `splits.csv` と一致。
2. 圃場363(2016年、開花日 2016-08-07)について、元の VWC 時系列から 2016-08-27〜09-15(開花後20〜39日)を手で切り出した20点が P3 の生の値と一致し、その1次差分が P3 の入力と一致。
3. Pipeline をそのまま回した結果と、特徴量を使い回した結果が一致(P1 と P5、乱数0、先頭10 fold)。
4. まとめて解いた置換20回分の帰無分布(全体・W・B)が、sklearn で1回ずつ学習した結果と一致(P3)。
5. 置換(市町村×年の中)5回分で分割が変わらない。

ほかに、60日全体(M_diff)の乱数0・先頭10 fold を計算し直して、段階13の `folds.csv` と一致した。

## 結果

[ ] は置換検定の p(補正前)。q95 は帰無分布の95%点。値は乱数10通りの平均。

| 窓 | 開花後の日 | 全体 AUC [p](q95) | **Holm 補正後 p** | bacc [p] | W [p] | B [p] | alpha が上限 |
|---|---|---|---|---|---|---|---|
| P1 | 0〜19 | 0.520 [0.51](0.601) | 1.00 | 0.493 [0.69] | 0.490 [0.59] | 0.527 [0.44] | 97% |
| P2 | 10〜29 | **0.448** [0.83](0.592) | 1.00 | 0.475 [0.77] | 0.455 [0.76] | 0.463 [0.77] | 100% |
| P3 | 20〜39 | 0.495 [0.56](0.594) | 1.00 | 0.499 [0.55] | 0.517 [0.40] | 0.496 [0.58] | 95% |
| P4 | 30〜49 | **0.588** [0.073](0.598) | 0.36 | 0.542 [0.13] | 0.536 [0.30] | 0.595 [0.062] | 96% |
| P5 | 40〜59 | **0.572** [0.071](0.580) | 0.36 | 0.551 [0.052] | 0.576 [0.11] | 0.569 [0.074] | 99% |
| 60日全体(段階13) | 0〜59 | **0.607 [0.026]**(0.592) | − | 0.573 [0.024] | 0.536 [0.30] | 0.640 [0.005] | 81% |

- 乱数による揺れは各窓で ±0.01 程度(P1 0.515〜0.529、P4 0.583〜0.593、P5 0.569〜0.579)。

### 問い1(主): 単独で偶然以上に見分けられる期間はあるか

- **Holm 補正後 p < 0.05 の部分窓は無い。** 補正前でも、どの窓も p ≥ 0.07 で95%点に届かない。
- 最も高いのは P4(開花後30〜49日、0.588、補正前 p = 0.073)と P5(40〜59日、0.572、p = 0.071)。補正後はどちらも p = 0.36。
- **結論: 20日の部分窓のどれも、単独で偶然以上に多収・低収を見分けられるとは言えない。**

### 問い2: 前半 P1 と後半 P5 に差があるか

- P5 − P1: AUC +0.052、繰り返し平均の2.5〜97.5%点 [−0.009, +0.109]、正の割合 0.95。
- **区間が0を含むので、差は検出できない。** 後半が高い向きではあるが、境界に近い。

### 期間ごとの AUC の形(記述)

- 形は「前半〜中盤が低く、後半が高い」。
  - P1(0〜19日)0.520 → P2(10〜29日)**0.448** → P3(20〜39日)0.495 → **P4(30〜49日)0.588** → P5(40〜59日)0.572。
  - P2 は0.5を下回る(帰無分布の平均とほぼ同じ水準より下だが、p = 0.83 で偶然の範囲)。
- 隣り合う窓の差(繰り返し平均の2.5〜97.5%点):

  | 比較 | AUC の差 | 区間 |
  |---|---|---|
  | P2 − P1 | −0.073 | [−0.116, −0.016](0を含まない) |
  | P3 − P2 | +0.047 | [−0.033, +0.104] |
  | **P4 − P3** | **+0.093** | **[+0.017, +0.170](0を含まない)** |
  | P5 − P4 | −0.015 | [−0.080, +0.032] |

  - 開花後30日前後を境に上がる向き。ただし隣り合う窓の差は4つ見たうちの1つで、補正はしていない(記述)。
- 各部分窓 − 60日全体: P1 −0.086、P2 −0.159、P3 −0.112(いずれも区間が0を含まず、低い)、P4 −0.019 [−0.080, +0.051]、P5 −0.034 [−0.069, +0.003]。**P4・P5 は、20日だけでも60日全体との差を検出できない**。
- 地域内・地域間: P4 は B 0.595(p = 0.062)で W 0.536、P5 は W 0.576(p = 0.11)・B 0.569。どの窓でも W は95%点に届かない。
- alpha はどの部分窓でも95〜100%で上限に張り付く(60日全体は81%)。

## 参考: 区間を消して学習し直す(記述のみ、判定には使わない)

60日の1次差分(59点)の10日の区間を0にして(その期間は変化なしとして)、同じ分割・同じ乱数で学習とテストをやり直した。置換はしない。

| 消した区間(1次差分の添字) | 開花後の日の変化 | AUC | 60日全体との差 [2.5〜97.5%点] |
|---|---|---|---|
| **0〜9** | **0〜10日** | **0.536** | **−0.071 [−0.121, −0.039]** |
| 10〜19 | 10〜20日 | 0.589 | −0.017 [−0.067, +0.021] |
| 20〜29 | 20〜30日 | 0.602 | −0.005 [−0.043, +0.033] |
| 30〜39 | 30〜40日 | 0.579 | −0.028 [−0.080, +0.022] |
| 40〜49 | 40〜50日 | 0.581 | −0.026 [−0.054, +0.001] |
| 50〜58 | 50〜59日 | 0.591 | −0.015 [−0.045, +0.011] |

**部分窓の結果との一致・不一致**
- **一致する点**: 中盤(開花後20〜30日)は、消しても AUC がほとんど変わらず(−0.005)、部分窓 P2・P3 も低い。この期間の動きは、ほとんど使われていないと考えられる。後半(30〜50日)は、消すとやや下がる向き(−0.026〜−0.028)で、部分窓 P4・P5 が高いことと同じ向き。
- **一致しない点**: **開花直後(0〜10日)を消すと最も大きく下がる**(−0.071、区間が0を含まない)。一方、その期間を含む P1 は単独で 0.520 と低い。
  - 考えられる理由(推測):
    - 開花直後の動きは、それだけでは役に立たず、後半の動きと組み合わさって効く(例: 開花時点からの乾き方・湿り方の変化を、長い dilation のカーネルが後半と結び付けて見ている)。部分窓では dilation が {1, 2} に限られるので、この組み合わせは見られない。
    - 区間を0にすると、系列の先頭にゼロが10点並ぶ不自然な形になり、MiniRocket のバイアス(分位点)や PPV が全体として変わる。下がった分には「その期間の情報」以外の影響も含まれる。
  - どちらかは今回の結果だけでは区別できない。

## 生育ステージとの対応について

- 開花(R1〜R2)から数えた日数を、そのまま生育ステージ(R3〜R6 など)に当てはめることはしていない。品種・播種日・地域で進み方が違い、圃場ごとのステージの記録も無い。
- 「R3〜R6 の水分ストレスが収量に効く」という仮説の材料は、AI が作った調査資料によるもので、**一次文献では未確認**。仮に開花後30〜60日がおおよそ莢伸長期〜子実肥大期に当たるとしても、今回の結果(P4・P5 が高い向き)は、補正後に有意ではなく、仮説を支持したとは言えない。

## 注意

- 部分窓は20日と短く、19点の1次差分だけで学習するので、60日全体より精度が下がるのは自然なこと。部分窓の AUC が低いことは、その期間に情報が無いことを示すものではない。
- 部分窓では dilation が {1, 2} に限られ、60日全体と同じ種類の特徴量ではない(上の「短い系列での MiniRocket」)。
- 5つの窓は10日ずつ重なっているので、互いに独立ではない(Holm 法は依存があっても使えるが、保守的になる)。

## 結論

- **問い1(主)**: Holm 補正後 p < 0.05 の部分窓は無い。20日の部分窓のどれも、単独で偶然以上に多収・低収を見分けられるとは言えない。最も高いのは P4(開花後30〜49日)0.588 と P5(40〜59日)0.572(補正前 p ≈ 0.07)。
- **問い2**: P5 − P1 は +0.052 [−0.009, +0.109] で、差は検出できない(後半が高い向き)。
- 記述として、期間ごとの AUC は「前半〜中盤が低く、開花後30日前後から上がる」形。P4・P5 は20日だけでも60日全体との差を検出できない。
- 参考の区間を消した結果は、中盤が使われていない点と後半が効く向きは部分窓と一致したが、開花直後(0〜10日)を消すと最も下がる点は一致しなかった。
- 主の設定は変えない(段階22は採用の判定をする実験ではない)。

## 次の候補(ユーザーと相談する)

- 開花直後の動きが後半と組み合わさって効くのかを確かめる(例: P1 と P5 をつないだ入力、または0にする代わりに区間を並べ替える・ノイズに置き換える)。判定を事前に固定して1回に限る。
- 窓を開花後30〜59日(P4 + P5 の範囲)に絞った入力を、事前の判定付きで60日全体と比べる。ただし今回の結果を見てから選んだ期間になるので、後からの仮説として扱う。
- 生育ステージとの対応を確かめるには、圃場ごとのステージの記録か、ステージを推定するモデルが必要(現状のデータには無い)。
