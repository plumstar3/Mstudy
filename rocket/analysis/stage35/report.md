## 目的

段階32(D-011)の検定A〜D を、**label_year**(同じ年の中の上位1/3・下位1/3)と **fixed 版のデータ(D-013)**に当てる。並べ替えは、同じ統計量について次の2通りで p を出す。

1. **年の中**(主)
2. **市町村×年の中**(地域の構成を固定した比較)

**label_year は地域の違いを含むラベルである。** 同じ年の中で収量の上位・下位を取るので、収量の高い地域の圃場は多収に、低い地域の圃場は低収に偏る。そのため年の中の並べ替えで差が出ても、それは地域(気象・土壌・センサーの設置条件・雨の時期)の違いかもしれず、**土壌水分の効果とは言えない**。

## 考察

### label_year の差は土壌水分の効果とは言えない

label_year は同じ年の中の上位・下位で、地域の違いを含む。年の中の並べ替えで差が出ても、地域の気象(雨の時期)・土壌・センサーの設置条件の違いかもしれず、土壌水分と収量の関係とは区別できない。

### 2通りの並べ替えの比較: 差は地域の違いによるか

- **年の中で出たもの**:
  - 検定C の D のクラスタ(開花後47〜48日、p = 0.003、z 3.22)と max-T(p = 0.050)
  - 2集団・10件だけの E_W(読まない、上記)
- **検定C の D のクラスタは、地域の構成を固定すると弱まった**(市町村×年の中で z 0.15〜1.36、p 0.064〜0.429)。形も、47〜48日に多収のほうが上がり、49・51日に下がる「雨の日の位置のずれ」である。開花起点で揃えた暦の時点ごとの検定(検定C)は、もともと雨の日のずれに敏感な対照として置いたもので、label_year では多収と低収で地域(=雨の日)の構成が違う。**この差は、多収の多い地域と低収の多い地域で雨の時期が違うことによる可能性が高い**(推測)
- 検定D の擬似 F も、年の中では z が正(1.28)、市町村×年の中では負(−1.48)で、同じ向きの変化をした
- 一方、主に見ていた D・N の energy(検定A)と雨後の応答曲線(検定B)は、年の中でも偶然の水準で、地域の違いを含めても差が見えなかった
- ただし、市町村×年の中の並べ替えで動くのは17集団・54件だけで、検出力は低い。「地域の構成を固定すると差が消えた」とは言えず、「地域の構成を固定した比較では差を検出できず、z も小さくなった」までが言えること

### 段階11(label_year の分類)との関係(参考)

段階11(EXP-020、旧データ)では、label_year で MiniRocket の分類が AUC 0.635(p = 0.005)だった。その中身は主に地域間(B 0.646)で、地域内は偶然の水準だった(段階12)。この段階でも、年の中で出た差は雨の時期の違いに当たる形で、地域の構成を固定すると弱まった。段階11・12の「label_year の分類は主に地域の違いを拾っている」という読み方と矛盾しない。

### ラベルを変えた探索であること

- この段階は、段階32の設定をそのままにして、データ(fixed)・ラベル(label_year)・並べ替え(2通り)を変えた探索である
- 段階32からの累計は456個の p で、補正前 p < 0.05 は38個、どの段階・どの補正の範囲でも Holm 後に p < 0.05 となったものは無い
- 年の中で補正前 p < 0.05 となった12個は、検定C の D(2個)と、2集団・10件の E_W(10個)だけである。主に見ていた D・N・N_post の検定ではない
- 差を検出できないことは関連が無いことを意味しない。また、仮説は同じデータの分類から作ったもので(double dipping)、この段階の補正前の結果を次の主の仮説にすると、同じデータで仮説を作り直すことになる
