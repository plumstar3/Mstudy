# 段階12: 段階11の M の性能を「地域内」と「地域間」に分ける

- 日付: 2026-11-06(EXP-021)
- 目的: 段階11(EXP-020)の M(MiniRocket・1次差分)の AUC 0.635 には、同じ市町村×年の中での圃場どうしの差(地域内)と、違う市町村の圃場の差(地域間)が混ざっている。テスト件のペアを種類ごとに分けて、M が当てているのがどちらかを調べる。あわせて、基準線 B2(緯度・経度・播種日)の AUC が0.5を下回った理由の仮説(グループ CV の負の偏り)を、同じ分け方で確かめる。

**スクリプト**: `analysis/stage12/run_stage12.py`(引数 `--n-perm` 1000、`--n-seeds` 10)。全体で163秒(28並列)。段階11の `outputs/stage11/folds.csv` が必要。

**出力**: `rocket/outputs/stage12/`(Git 管理外)

| ファイル | 内容 |
|---|---|
| `run_log.txt` | 実行ログ(ペア数、事前確認、結果) |
| `oof_scores.csv` | 1行1件のテスト件の決定関数の値(設定・乱数・繰り返し・fold ごと) |

## 設定

データ・モデル・分割は段階11と同じ。

- データ: `data/processed/stage11/` の162件。
- 設定: M・B1・B2 の3つ。主データだけで行い、S は行っていない。
- M は乱数0〜9。
- 分割: `make_splits(y, muniCd, 5, 20, 0)`。

**ペアの分け方**: 同じ(乱数, 繰り返し, fold)のテスト件どうしで、多収 × 低収の組だけを数える。fold が違うとモデルが違い、スコアを比べられないため。

| 種類 | 定義 | 1回の繰り返しあたりのペア数(平均 / 最小 / 最大) |
|---|---|---|
| W 地域内 | 同じ市町村×年 | 41 / 41 / 41 |
| B 地域間 | 同じ年で、違う市町村 | 459 / 414 / 512 |
| X 年をまたぐ(参考) | 違う年 | 825 / 748 / 918 |

- AUC = スコアの大小がラベルと合うペアの割合(同点は0.5)。乱数・繰り返しごとに fold をまたいでペアを合算して AUC を出し、20回の繰り返しで平均し、乱数10通りでも平均した。
- W に寄与するのは、両方のクラスがそろう市町村×年の **17集団(54件)**。集団は fold をまたがない(groups=muniCd)ので、W のペア数はどの繰り返しでも41組。全ペアの約3%にあたる。
- 判定(事前に固定): 主 = M の W の AUC が、W の帰無分布の95%点を上回るか。副 = M の B と B の帰無分布の比較。多重比較の補正はしない。

### 分割を固定した置換検定

| 帰無分布 | 並べ替えの単位 | 回数 |
|---|---|---|
| W | 市町村×年の中(集団のクラス構成を保つ) | 1000 |
| B | 年の中(段階11と同じ) | 1000 |

- 置換 i の乱数は [0, i]。M の帰無分布は、置換 i ごとに乱数10通りで平均した。
- 分割は、段階11と同じく観測ラベルで作ったものを、すべての置換で固定して使った。
  - W の置換では、集団のクラス構成が変わらないので、分割は置換前と同じになる。
  - B の置換(年の中)では地域ごとのクラス数が変わるので、作り直せば分割は変わる。B の帰無分布は「この分割のもとで」の分布になる。
- M の置換は `run_stage6_local._batched_ridge` でまとめて解いた。判定があいまいな行は RidgeNTrain で学習し直した(乱数ごとに0〜2組)。B1・B2 は LR を1回ずつ学習した。

**開始時の確認**(すべて True)
1. 置換20回分(W・B、M、乱数0)について、まとめて解いた帰無分布と、sklearn で1回ずつ学習した帰無分布が完全に一致する。
2. 保存したスコアから計算し直した fold の AUC が、`outputs/stage11/folds.csv` と一致する(M は乱数10通りすべて、B1・B2。最大差 1.1e−16)。
3. W・B・X をペア数で重み付けして合わせると、fold の AUC と一致する(同上)。

## 結果

[ ] は置換検定の p。q95 は帰無分布の95%点。

| 設定 | W 地域内 | W の帰無分布 平均 / q95 | B 地域間 | B の帰無分布 平均 / q95 | X 年をまたぐ(参考) |
|---|---|---|---|---|---|
| **M** | **0.526 [0.40]**(乱数 0.516〜0.541) | 0.503 / 0.649 | **0.646 [0.006]**(乱数 0.641〜0.651) | 0.501 / 0.597 | 0.627(0.620〜0.633) |
| B1 VWC の要約統計 | 0.472 [0.62] | 0.497 / 0.650 | 0.596 [0.053] | 0.503 / 0.596 | 0.527 |
| B2 緯度・経度・播種日 | 0.396 [0.96] | 0.499 / 0.634 | 0.416 [0.91] | 0.500 / 0.596 | 0.407 |

### 判定

- **主: M の W(地域内)は 0.526 で、95%点 0.649 に届かない(p = 0.40)。「地域内でも当たっている」とは言えない。** 乱数10通りのどれでも 0.516〜0.541 で、95%点を大きく下回る。
- **副: M の B(地域間)は 0.646 で、95%点 0.597 を上回る(p = 0.006)。**
- 段階11の M の AUC は、ほぼ地域間(B)と年をまたぐペア(X)で決まっている。W はペアの約3%しかない。

### W のペア数と検出力の限界

- W は1回の繰り返しあたり41組(17集団)しかない。集団は fold をまたがないので、繰り返しを重ねても、同じ41組を違うモデルで採点し直すだけになる。
- W の帰無分布は標準偏差 0.087 と広く、95%点は 0.649。B(標準偏差 0.059、95%点 0.597)より、0.05 ほど高い値が必要になる。
- 正規近似での目安: 検出力80%で検出するには、本当の W の AUC が約0.72(0.5 + (1.645 + 0.84) × 0.087)必要になる。M の B(0.646)程度の効果が地域内にあっても、この検定では見つけられない見込みが高い。
- したがって、**「地域内では当たっていない」とも言えない。** 言えるのは「地域内の効果は、あったとしても、この件数では検出できない大きさ」ということまで。
- 集団ごと(`within_groups.csv`)の M の W:
  - AUC が0.5を上回る集団が10、下回る集団が7。ペア数で重み付けすると 0.526。
  - 高い集団: 23212_2016(5件、6ペア、0.999)、8201_2016(0.872)、32203_2017(0.732)。
  - 低い集団: 20202_2016(5件、4ペア、0.000)、15202_2016(0.025)、32206_2016(0.102)。
  - 集団ごとに当たり外れがはっきり分かれ、全体ではほぼ相殺している。ペアが1〜6組なので、集団ごとの値は記述にとどめる。

### B2 の負の偏りの仮説

- 仮説: 「B2 の AUC が0.5を下回るのは、地域単位の分割で、場所の特徴が未知の地域に逆向きに当てはまるため(段階11の report.md の推測)」。これが正しければ、地域間(B)のペアで0.5を下回るはず。
- 結果: **B2 の B は 0.416 で0.5を下回り、仮説と矛盾しない。** ただし、B の帰無分布の中では下側約9%で、偶然でも出る範囲にある(5%点 0.398)。
- **一方、W(0.396)と X(0.407)も同じ程度に0.5を下回る。** 0.5を下回るのは地域間のペアに限らないので、「地域間で逆向きに当てはまる」という形の仮説は、この結果だけでは支持されない。
  - 推測: 学習した係数の向き(とくに播種日の通日)が、テスト側では全体として逆に当たっている。同じ市町村×年の中でも播種日や位置はわずかに違うので、その差で逆向きに順位が付く。確かめてはいない。
- B2 の W は、W の帰無分布の下側約4%(5%点 0.400)。

### その他

- B1(VWC の要約統計)は、B では 0.596(p = 0.053、95%点ちょうど)まで上がる。W(0.472)と X(0.527)はほぼ偶然水準。B1 も、効いているとすれば地域間。M との差の検定はしていない。
- X(年をまたぐ)は、label_year が年の中の順位なので、「ある年の多収」と「別の年の低収」の比較になる。年の差(気象など)が入るので参考にとどめる。段階11の fold の AUC では、ペアの約6割がこの種類。

## まとめ

- 段階11の M(AUC 0.635)は、**地域間(同じ年・違う市町村)のペアでは 0.646 で当たっている(p = 0.006)が、地域内(同じ市町村×年)のペアでは 0.526 で、帰無分布の95%点 0.649 に届かない(p = 0.40)。**
- 地域内のペアは41組(17集団)しかなく、検出力が低い(80%で検出するには AUC 約0.72が必要)。このため、地域内の効果は「無い」のではなく「この件数では確かめられない」。
- 段階11の結果は、主に地域間の差(土壌や気候の違いが VWC に現れたもの)を拾っていると読める。土壌水分そのものの効果を示す材料にはならない。
- B2 は W・B・X のどれでも0.5を下回る。地域間に限った負の偏りという形の仮説は支持されない。

## 次の候補(ユーザーと相談する)

- 地域内の検出力を上げる: 地域内のペアが多いラベル(`label_muniyear_median_min2`、282件・59地域。2圃場以上の集団すべてに多収/低収が付く)で、同じ W の分け方を行う。
- B2 の係数の向きを fold ごとに集計し、学習側とテスト側で関係が逆になっているかを確かめる。
- M と B1 の地域間(B)での差を、同じ分割の fold ごとの差で比べる。
