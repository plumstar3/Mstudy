# 段階17: MultiRocket のプーリング(PPV・MPV・MIPV・LSPV)による特徴量の比較

- 日付: 2026-11-09(EXP-026)
- 目的:
  - MiniRocket は、畳み込みの出力から PPV(正の値の割合)しか取り出さない。
  - MultiRocket(Tan et al., 2022)は、さらに MPV(正の値の平均 = 強さ)、MIPV(正の値の位置の平均 = 時期)、LSPV(正の値が続いた最長の長さ = 持続期間)を取り出す。

- **試した回数: 特徴量(プーリング)の変更は今回が初めて。**

## 実装の確認(`implementation_check.txt`)

sktime 1.2.0 の `sktime/transformations/rocket/_multirocket.py` と `_multirocket_numba.py` を読んだ。実行の時点では論文の PDF が見当たらなかったので、確認はソースで行った。実行の後で `docs/papers/MultiRocket.pdf` が置かれたので、論文との照合を下の「論文との照合(実行後に追加)」に書いた。

1. **設計**: 論文どおり、入力の系列と内部の1次差分の両方を使う。
   - `_fit` で、入力 X のパラメータ(dilation・バイアス)と、`np.diff(X, 1)` のパラメータを別々に作る。
   - `_transform(X, X1 = np.diff(X, 1), parameter, parameter1, 4)` を呼ぶ。
2. **並び順**: 出力は (nf + nf1) × 4 列。nf = 84 × (num_kernels // 84) で、入力の系列と内部の差分で同じ数。
   - 前半(列 0〜4·nf−1)が入力の系列で、列 j が PPV、j + nf が LSPV、j + 2nf が MPV、j + 3nf が MIPV。
   - 後半(全列の半分から)が内部の1次差分で、同じ並び。
3. **値**:
   - PPV = 正の数 / 長さ。
   - LSPV = バイアス未満の値の間隔の最大(正の値が続いた最長の長さ)。
   - MPV = Σ(C + bias) / 正の数。正が無ければ0。和が C − bias ではなく C + bias なのは sktime の実装のまま(論文の式とは違う)。
   - MIPV = 正の位置の平均。正が無ければ −1。
   - 最後に `np.nan_to_num` をかける。
4. 入力の系列のパラメータ(バイアス)は X だけから作られ、内部の差分のパラメータとは独立している。

**取り出し方**: 1次差分(59点)を MultiRocket(num_kernels=2520)に入力する。出力 20160 列のうち、前半の列 0〜10079(入力の系列 × 4種類、**10080 特徴量**。M_diff は 9996)を使う。内部で作る「1次差分の差分」の部分は捨てる。

**確認(すべて True)**
- 出力の列数 = 8 × 2520。
- 小さな乱数の入力で、numba の `_transform` に渡す「内部の差分」だけを乱数に入れ替えた。前半(入力の系列)の特徴量は完全に同じで、後半だけが変わった。
- `_transform` を直接呼んだ結果が、sktime の `transform` の結果と一致した。
- 並び順を値の範囲で確かめた(実データの1次差分123件、乱数0)。
  - PPV は 0〜1、LSPV は 0 以上59未満の整数、MIPV は −1 以上59未満。
  - PPV = 0 の所では、MPV = 0・MIPV = −1 になっている。
- **値**: NaN 0、inf 0。正の値が無い(PPV = 0)特徴量は4.6%で、このとき MPV は0、MIPV は −1 で埋められる。0での割り算は起きない。

### 論文との照合(実行後に追加)

`docs/papers/MultiRocket.pdf`(Tan et al., *Data Mining and Knowledge Discovery* 36, 2022)の 3.2〜3.5節と付録 A の Algorithm 1 と照らし合わせた。

| 項目 | 論文 | sktime 1.2.0 | 一致 |
|---|---|---|---|
| 系列の表現 | 元の系列と1次差分の両方に、同じ84カーネルをかける。dilation・バイアスは表現ごとに別(長さと値の範囲が違うため) | 同じ(`parameter` と `parameter1`) | ○ |
| バイアス | カーネル・dilation の組ごとに、ランダムに選んだ学習例の畳み込み出力の分位点 | 同じ(`_fit_biases`) | ○ |
| PPV | 正の値の割合(式2) | 正の数 / 長さ | ○ |
| MPV | **正の値 z⁺ の平均**(式3)。z は畳み込み出力からバイアスを引いた値なので、Σ(C − bias) / m | **Σ(C + bias) / m** | **×** |
| MIPV | 正の値の位置の平均、正が無ければ −1(式4) | 同じ | ○ |
| LSPV | 正の値が続いた最長の長さ(式5、Algorithm 1 の last_val・max_stretch) | 同じ手順(Algorithm 1 と同じ書き方) | ○ |
| 既定の特徴量の数 | 49,728(6,216 × 2表現 × 4種類) | 49,728(MR_std と同じ) | ○ |
| 特徴量の並び | Algorithm 1 は (PPV, MPV, MIPV, LSPV) の順に返す | ブロックの順は PPV, LSPV, MPV, MIPV | 並びだけ違う(取り出しはソースの順で行ったので問題ない) |

**MPV のずれ**
- sktime の MPV は、論文の MPV に 2 × bias を足した値になっている(正の値がある所だけ。正が無い所はどちらも0)。
- 列ごとにほぼ一定のずれなので、Ridge の切片でほとんど吸収される。ただし、正の値が無い所(4.6%)では足されないこと、StandardScaler の尺度が少し変わることから、結果は完全には同じにならない。
- 探索的な確認(置換なし、判定には使わない): MPV を論文の式に直して MR4_diff を学習し直すと、全体の AUC は乱数0〜2で 0.588 → 0.591、0.592 → 0.596、0.591 → 0.596(+0.003〜+0.005)。fold ごとの差は最大0.09。スクリプトはスクラッチパッドの一時ファイルで、リポジトリには保存していない。
- **採用の判定への影響**: 平均が +0.004 程度動くと、基準2(0.592 vs 95%点 0.593)は境界のため、満たす側に変わる可能性がある。一方、基準1(MR4_diff − M_diff の区間 [−0.053, +0.013])は、+0.004 動いても0を含む。採用には両方が必要なので、**判定(採用しない)は変わらない**。
- 本番は sktime の実装のまま行い、その値を記録する。論文の式に直して置換検定までやり直すことはしていない(試す回数を増やさないため)。

## 採用の判定

| 基準 | 結果 | 満たすか |
|---|---|---|
| 1. MR4_diff − M_diff の繰り返し平均の 2.5〜97.5%点が0より上 | [−0.053, +0.013] | **満たさない** |
| 2. MR4_diff の全体の AUC が帰無分布の95%点を上回る | 0.592 < 0.593(p = 0.056) | **満たさない**(境界) |

- **MR4_diff は採用しない。主の設定は M_diff のまま変えない。**
- MR4_diff は M_diff より平均で0.015低いが、差は検出できない(区間が0を含む)。「4種類のプーリングで良くなる」とは言えない。悪くなるとも言えない。
- 採用しなかったので、段階15の部分集合での学習し直しは行っていない。

## W・B の変化

- **W(地域内)**: 0.536 → 0.542。差 +0.006、市町村単位のブートストラップの95%区間は [−0.054, +0.063]。変わらない。
- **B(地域間)**: 0.640 → 0.594(p = 0.033 で95%点 0.583 は上回る)。B が少し下がった分、全体の AUC が下がった。
- 「反応の強さ・時期・長さ」を加えても、地域内の判別は良くならなかった。

## alpha の張り付きの変化

- 上限に張り付いた fold の割合: M_diff 81% → MR4_diff 86% → MR_std 99.7%。
- 特徴量の種類を増やすと、強い正則化がより多く選ばれる。MR_std はほぼすべての fold で上限で、切片だけに近いモデル。
- 参考2では、特徴量が2520の「PPV のみ」で27%、5040で36〜70%、10080で86%と、特徴量の数とともに上がる。

## プーリングの内訳(参考2、記述のみ・判定には使わない)

MR4_diff の特徴量の行列から部分集合を取り出し、同じ分割・同じ乱数で Ridge を学習・評価した(置換なし)。

| 部分集合 | 特徴量 | 全体 AUC(乱数の幅) | bacc | − PPV のみ(繰り返し平均の2.5〜97.5%点) | alpha が上限 |
|---|---|---|---|---|---|
| PPV のみ | 2520 | 0.600(0.598〜0.604) | 0.561 | − | 27% |
| PPV+MPV | 5040 | **0.603**(0.600〜0.608) | 0.561 | +0.003 [−0.027, +0.027] | 36% |
| PPV+MIPV | 5040 | 0.578(0.574〜0.585) | 0.551 | −0.022 [−0.064, +0.013] | 58% |
| PPV+LSPV | 5040 | 0.584(0.581〜0.588) | 0.556 | −0.016 [−0.054, +0.017] | 70% |
| 4種類すべて | 10080 | 0.592(0.588〜0.594) | 0.572 | −0.008 [−0.051, +0.026] | 86% |

- どのプーリングを加えても、PPV のみとの差は検出できない。
- MPV(強さ)はほぼ変わらず、MIPV(時期)と LSPV(持続期間)はわずかに下がる向き。
- 「PPV のみ」(MultiRocket のバイアスの取り方で2520特徴量)でも 0.600 と、M_diff(MiniRocket、9996特徴量)とほぼ同じ。この課題での情報は、PPV でほぼ取り出せていると考えられる(推測)。
- 部分集合ごとの値は、試す回数を増やさないための記述にとどめる。どれかを選び直すことはしない。

## MR_std との比較

- 論文どおりの標準構成(生の値 + 1次差分 × 4種類、約5万特徴量)は 0.547 で、偶然水準(p = 0.22、置換200回)。M_diff との差は −0.060 で、悪化を検出した。
- 入力に生の値が入ることと、特徴量が5倍になって alpha がほぼすべての fold で上限に張り付くことが、下がった理由と考えられる(推測)。
  - 生の値は、段階7(EXP-009)と段階16の探索で、単独では偶然水準だった。
- この課題(123件・水準差の大きいセンサー)では、標準構成をそのまま使うのは向かない。

**探索的な追加(実行後、判定は事前に決めていない)**: 2つの理由を分けるために、MR_std と同じ構成(生の値 + 1次差分 × 4種類)で num_kernels=1260(10,080特徴量)にした。同じ123件・同じ分割・乱数0〜9、置換なし。スクリプトは一時ファイルで、リポジトリには保存していない。

| 設定 | 特徴量 | 全体 AUC(乱数の幅) | W | B | alpha が上限 |
|---|---|---|---|---|---|
| MR_std・約1万 | 10,080 | 0.534(0.530〜0.536) | 0.522 | 0.519 | 98% |
| MR_std | 49,728 | 0.547 | 0.517 | 0.550 | 99.7% |
| MR4_diff | 10,080 | 0.592 | 0.542 | 0.594 | 86% |

- 約1万 − MR_std: −0.014 [−0.047, +0.014] で、差は検出できない。約1万 − MR4_diff: −0.058 [−0.100, −0.033] で、低い。
- 特徴量を減らしても変わらず、同じ1万でも生の値が入ると下がる。**MR_std が低かった主な理由は、特徴量の多さではなく生の値が入ったこと**と考えられる。1万でも alpha は98%で上限に張り付く。

## 結論

- 4種類のプーリング(MR4_diff)は、採用の基準を満たさない(差 −0.015 [−0.053, +0.013]、0.592 は95%点 0.593 に届かない)。**主の設定は M_diff(1次差分 → MiniRocket の PPV)のまま。**
- 地域内 W は変わらず(0.536 → 0.542)、地域間 B は少し下がった(0.640 → 0.594)。
- 内訳では、MPV・MIPV・LSPV のどれを加えても PPV のみとの差は検出できない。特徴量が増えるほど alpha の張り付きが増える。
- MultiRocket の標準構成は 0.547 で偶然水準。

- 特徴量の数を減らす方向(MiniRocket の num_kernels を小さくする)で、alpha の張り付きと AUC の関係を見る。参考2で、特徴量が少ないほど張り付きが減ったため。ただし、試す回数が増えるので、判定を事前に固定して1回に限る。
