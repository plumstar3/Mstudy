# 段階28: 減る動き(N)の情報を3つの方向から確かめる(EXP-037)

- 日付: 2026-11-17
- スクリプト: `analysis/stage28/run_stage28.py`(`rocket\venv_rocket\Scripts\python rocket\analysis\stage28\run_stage28.py --part A`、`--part B C`)。部分Aは1秒、部分B・Cは28並列で数分。試運転は `--part B C --n-seeds 1 --n-perm 20 --n-boot 50`
- 出力: `outputs/stage28/`(部分A `partA_diff.csv`・`partA_bootstrap.csv`、部分B `partB_summary.csv`・`partB_per_seed.csv`・`partB_w_diff_bootstrap.csv`・`null_partB_N_*.npy`・`partB_w.png`、部分C `partC_summary.csv`・`partC_per_seed.csv`・`null_partC_N_*.npy`・`partC_years.png`、`run_log_A.txt`・`run_log_B_C.txt`・`stdout_B_C.txt`、途中結果 `partial/`)
- 入力: `data/processed/stage27/` の N と、段階13の窓から計算した D(1次差分)。段階27の入力・出力は変更していない

## 目的

段階27(EXP-036)の「減る動き(N = min(Δθ, 0))に情報がありそう」という結果を確かめる。

- **Q1(部分A)**: N は増える動き(P)より多くの情報を持っているか(N − P)
- **Q2(部分B)**: N の地域内 W(段階27で 0.613、p = 0.040)は、乱数を変えて判定を事前に固定しても再現するか(同じデータの中での再確認)
- **Q3(部分C)**: N の地域内 W は、年をまたいでも再現するか

変換器・分類器・置換の仕方は段階27と同じ(MiniRocket(10000)→ StandardScaler(with_mean=False)→ RidgeClassifierCV(logspace(−3, 3, 10) × n_train)、置換は市町村×年の中でラベルを並べ替える)。W・B は段階12・13と同じ定義。主の設定(M_diff)を変えるかどうかは、この段階では判定しない。

## 部分A: N − P(Q1、回し直しなし)

### 方法
- 段階27の `bootstrap_auc.csv` は、入力ごとの全体 AUC がリサンプルの番号ごとに同じ行にある(確認A1: True)。同じ番号どうしで N − P を取り、95%区間を出した(市町村単位のクラスターブートストラップ、2000回)
- W・B の N − P は、段階27の `partial_N.pkl`・`partial_P.pkl` のスコアから、段階27と同じ乱数の列でリサンプルして計算した。計算し直した全体 AUC は、2000リサンプルすべてで `bootstrap_auc.csv` と一致した(確認A2: True)
- 判定: 区間が0より上 → 減る動きのほうが情報が多い / 0を含む → 差は検出できない。**この比較は段階27の結果を見てから決めた事後の比較(探索的)**

### 結果
| 指標 | N − P(点推定) | 95%区間 | 正の割合 | 役割 |
|---|---|---|---|---|
| 全体 AUC | +0.048 | [−0.031, +0.140] | 89% | 判定 |
| 地域内 W | +0.100 | [−0.048, +0.261] | 91% | 記述 |
| 地域間 B | +0.033 | [−0.057, +0.128] | 77% | 記述 |

(点推定は段階27の値の差。全体は fold の AUC の平均、W・B は繰り返しごとに合算して乱数で平均)

**判定: 区間が0を含み、N と P の差は検出できない。** N の方が高い向きだが、P の全体 AUC(0.577)も偶然の水準よりやや上にあり、「減る動きの方が多くの情報を持つ」とまでは言えない。

## 部分B: N の地域内 W の再確認(Q2)

### 方法
段階20(EXP-029)と同じ方法。乱数は段階27と重ならないもの: カーネル10〜19、分割 `make_splits(y, muniCd, 5, 20, 20)`(分割の乱数20〜39。100 fold すべてで段階27と同じ位置の fold のテスト件が違う)、置換 i の乱数は [1, i]・200回。判定に使うのは N の W だけで、事前に固定した(検定は1つ、補正なし)。D は同じ乱数・分割で計算し、置換は省略した(記述)。

- 置換の回数: 依頼どおり200回。段階20では判定に使った R_all が1000回、記述の M_diff が200回だった

開始時の確認(すべて True): 入力の並びと N = min(Δθ, 0)、分割と乱数が段階27と重ならない、置換しても分割が変わらない、まとめて解いた置換 = sklearn(N、乱数10、置換20回)、20の (入力, 乱数) で fold の AUC・bacc が sklearn と一致し W+B+X = fold の AUC。

### 結果
| 入力 | 全体 AUC [p](q95) | bacc [p] | **W [p](q95)** | B [p](q95) | alpha が上限 |
|---|---|---|---|---|---|
| N | 0.623 [0.005](0.595) | 0.580 [0.015] | **0.614 [0.090](0.629)** | 0.625 [0.015](0.595) | 48% |
| D(置換なし) | 0.608 | 0.575 | 0.539 | 0.635 | 77% |

- N の W の乱数の幅: 0.607〜0.618
- W の N − D: +0.076、市町村のブートストラップ95%区間 [−0.037, +0.199](正の割合 89%)

**判定: N の W は95%点に届かず(0.614 < 0.629、p = 0.090)、同じデータの中で再現しなかった。**

## 部分C: 年をまたいだ確認(Q3)

### 方法
段階21(EXP-030)と同じ leave-one-year-out。テストの年は2016年(79件、W のペア92)と2017年(37件、W のペア49)。学習はほかの年の123件の中の全件(2016年のテストでは44件、2017年では86件。2018年は学習だけ)。カーネルの乱数0〜9、置換 i の乱数は [2, i]・200回。判定: N の W(2年合わせ、141組)が帰無分布の95%点を上回るか。D は置換なし(記述)。

開始時の確認: D_LOYO が段階21の M_diff_LOYO と、乱数0〜9のすべてで W・B・年ごとの指標まで一致した(確認C1: True)。各年・各乱数で AUC が sklearn と一致し、W+B+X = 年ごとの AUC。

### 結果
| 設定 | **W(2年)[p](q95)** | B(2年) | 全体(2年の平均) | 2016年 W / B / 全体 | 2017年 W / B / 全体 |
|---|---|---|---|---|---|
| N_LOYO | **0.616 [0.075](0.623)** | 0.639 [0.025] | 0.640 [0.030] | 0.584 / 0.639 / 0.635 | **0.676** / 0.640 / 0.645 |
| D_LOYO(置換なし) | 0.504 | 0.641 | 0.617 | 0.550 / 0.644 / 0.639 | 0.416 / 0.625 / 0.595 |
| 参考: M_diff_LOYO(段階21) | 0.504 [0.52] | 0.641 | 0.617 | 0.550 / 0.644 / 0.639 | 0.416 / 0.625 / 0.595 |
| 参考: R_all_LOYO(段階21) | 0.538 [0.27] | 0.588 | 0.580 | 0.567 / 0.588 / 0.587 | 0.484 / 0.588 / 0.573 |

- N の W(2年)の乱数の幅: 0.596〜0.631。2017年の W は乱数10通りすべてで 0.653〜0.694

**判定: N の W は95%点に届かず(0.616 < 0.623、p = 0.075)、年をまたいで再現したとは言えない。**

- **2017年の並びの向き**: 段階21では、R_all(0.484)・M_diff(0.416)とも2017年の地域内の並びが逆向きだった。**N では2017年の W が 0.676 で、逆向きにならなかった**(乱数10通りすべてで 0.65 以上)。2016年は 0.584 で、D(0.550)よりやや高い
- 年をまたいでも、N の全体 AUC(0.640)と B(0.639)は偶然の水準を上回った(記述)

## 解釈

| 部分B | 部分C | 事前に決めた解釈 |
|---|---|---|
| 再現せず(p = 0.090) | 再現せず(p = 0.075) | 段階27の W は偶然の可能性が高い |

事前の目安に従えば、**「段階27の N の地域内 W(p = 0.040)は偶然の可能性が高い」**となる。ただし、次の点もあわせて記録する。

- N の W の点推定は、3つの設定でほぼ同じだった(段階27 0.613、部分B 0.614、部分C 0.616)。変わったのは帰無分布の95%点(0.600 → 0.629・0.623)で、値が下がって再現しなかったのではなく、どの設定でも p = 0.04〜0.09 の境目付近にある
- W のペアは141〜147組しかなく、帰無分布の SD から求めた検出力80%に必要な W は 0.665(段階27)・0.670(部分B)・0.693(部分C)。N の W が本当に0.61前後なら、この件数では毎回5%を超えたり下回ったりしうる。「偶然の可能性が高い」というより「この件数では偶然と区別できない」と読むのが正確と考える
- D の W(0.50〜0.54)とは違い、N の W は2017年でも逆向きにならなかった。年によって関係が変わる D・R_all とは形が違う(記述、検定していない)
- 部分A では、N と P の差も検出できない。「減る動きの方に情報が多い」は、向きは一貫しているが確かめられていない

主の設定(M_diff)を N に変えるかどうかは、この段階では判定しない。
