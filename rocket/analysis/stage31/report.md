## 方法

### 入力

1時間(θ(h) = 窓の中の1時間ごとの VWC、Δθ(h) = θ(h) − θ(h−1)、1439点):

| 記号 | 入力 | 定義 | 役割 |
|---|---|---|---|
| H_raw | 生の値 | θ(h)(1440点) | 主(判定) |
| H_D | 1次差分 | Δθ(h) | 主 |
| H_N | 減る方向の1次差分 | min(Δθ(h), 0) | 主 |
| H_Npost | 雨の直後の減少 | H_N のうち雨の直後の時間だけ残し、ほかは0 | 主 |
| H_Ndry | 無降雨日の減少 | H_N のうち雨の日でも雨の直後でもない時間だけ残し、ほかは0 | 主 |
| H_Npost_night | 雨の直後の夜の減少 | H_Npost のうち 18:00〜翌6:00 | 探索(記述) |
| H_Npost_day | 雨の直後の昼の減少 | H_Npost のうち 6:00〜18:00 | 探索(記述) |

日平均(段階27・29と同じ定義。60日の日平均から。Δθ は日平均の1次差分): Dy_raw(60点)、Dy_D、Dy_N、Dy_Npost、Dy_Ndry(59点)。日平均の雨の日・雨の直後は段階29の `components` をそのまま使った。

**雨の日・雨の直後**

- 雨の日: 同じ件の日平均で Δθ > 0 の日(段階29と同じ)。1時間の Δθ > 0 は使わない。1時間で上がる時間は、雨の日でない日にも 6.7% ある(雨の日では 25.5%、雨の日でない日の上昇の中央値 0.00065)
- 窓の最初の数日は、開花日より前の日平均(θ(−4) 〜 θ(−1))を使って日 −3 〜 0 の雨の日を判定した。119件中115件は4日分すべてあり、4件は一部が欠けている(欠けた日は「雨の日なし」として扱う)
- 雨の直後: 雨の日の翌日から3日目まで(k = 3)のうち、雨の日でない日のすべての時間。雨の日が続く場合は最後の雨の日から数える
- 雨の日当日の時間は、H_Npost にも H_Ndry にも入れない
- Δθ(h) がどの日に入るかは、θ(h) の時刻の暦日で決めた(23:00 → 0:00 の区間は翌日に入る)
- 昼夜は θ(h−1) → θ(h) の1時間の区間で決めた。夜は区間が 18:00〜翌6:00 に入るもの(θ(h) の時刻が 19:00〜6:00)、昼は 6:00〜18:00 に入るもの(7:00〜18:00)で、12時間ずつになる。**昼夜の区切りは固定の時刻で、日の出・日の入りには合わせていない**。考え方は「夜はほとんど蒸散が起きないので、夜の減少は主に排水、昼の減少は排水と蒸散を反映する」だが、季節や地域による日長の違いは考慮していない

| 項目 | 結果 |
|---|---|
| 雨の日の数(件ごと、60日中) | 平均 18.5、中央値 18、最小 11 〜 最大 26(5・95%点 14・23.1) |
| 雨の直後(k = 3)/ 無降雨日 | 平均 25.3日 / 16.2日 |
| 段階29(旧日平均)の雨の日との一致率(共通118件、日1〜59) | 0.9973(103件は完全に一致。一致しない日がある15件はすべて2016年で、1件あたり1〜2日。旧データでの小数第3位の丸めで、小さな Δθ の符号が変わったためと考えられる)。雨の直後の一致率は 0.9967 |
| H_Npost の減少量のうち夜の区間の割合(件ごと) | 平均 0.355、中央値 0.351(多収 0.343、低収 0.367) |

- 図 `rain_day_examples.png` から分かること: 夕方以降に雨が降ると日平均は翌日も上がるので、翌日も雨の日になる(例: field 575 の2〜4日目)。このため、雨のピークの直後の減少の一部は「雨の日当日」に入り、H_Npost から外れる。日平均で雨の日を決めたことによる性質で、1時間の H_Npost は「雨の後の急な排水」の最初の部分を取りこぼすことがある

## 考察

- **データの修正で結論は変わらなかった(日平均)**。旧データの誤り(362 の J11 混入、607・609 の出所不明の値、2016年の丸め)を直し、件数が4件減っても、雨の直後の減少 Dy_Npost は全体 AUC 0.658 で、5つの入力の Holm 補正の後でも基準をわずかに上回った。雨の日の判定も旧と 99.7% 一致した。「多収・低収の情報は雨の後の減り方にある」という段階29の読みは、新しいデータでも支持される。ただし Holm 後 p = 0.0498 は基準の境目で、余裕は小さい
- **1時間にしても良くならず、むしろ下がる向きだった**。同じ件・同じ形どうしで、1次差分・減る方向・雨の直後の減少は1時間のほうが 0.09〜0.10 低い(補正後は差を検出できない)。1時間の主の入力はどれも偶然水準を上回らなかった。考えられる理由(推測):
  1. MiniRocket の特徴量の配分: 1440点では dilation が26種類に分かれ、日平均の1日刻みに当たる dilation 24 にはカーネル1本あたり4つしか特徴量が割り当てられない。特徴量の多くは数時間以内の細かい変化(センサーのノイズ、昼夜の周期、夜間の水の再分布)に使われる
  2. 1時間の Δθ は値が小さく、ノイズの割合が大きい。alpha が上限に張り付く割合は H_D で99%(Dy_D は82%)で、モデルがほぼ切片だけに近づいている
  3. 2時間間隔のシートの8件は、補間で1時間の Δθ が2つずつ同じ値になり、1時間の入力でだけ形が違う(低収に偏る。上の「interpolated の割合」)
  
  このどれが効いているかは、この段階では切り分けていない
- **生の値だけは1時間のほうが少し高い向き**(+0.036、検出できず)。どちらも偶然水準で、意味のある差とは言えない
- **昼夜(探索的)**: 夜の減少 H_Npost_night(0.574)は昼 H_Npost_day(0.532)より高い向きだが、差は検出できない(+0.042、p = 0.56)。夜の減少は H_Npost の減少量の約35%しかないのに H_Npost 全体(0.572)と同じ程度で、alpha の張り付きも 11% と少ない。「夜の減少(主に排水)に情報が集まっている可能性」はあるが、探索的な結果で、昼夜の区切りも固定の時刻なので、結論には使わない
- 雨の直後の減少で1時間が日平均より低い理由の一つとして、日平均で雨の日を決めたため、雨のピークの直後の急な減少の一部が「雨の日当日」に入り H_Npost から外れることもありうる(推測)。日平均の Dy_Npost では、その日の減少は日平均の差として雨の日に吸収されるので、同じ情報の取りこぼし方ではない
- W は記述(D-007)。Dy_Npost の W 0.629(p = 0.045)は段階29の N_post(0.634)とほぼ同じ

## 限界

- 1時間の入力の結果は「MiniRocket(10000)を1440点にそのままかけた場合」の結果で、1時間のデータに情報が無いことを示すものではない。dilation の範囲・特徴量の配分・平滑化などは変えていない
- 2時間間隔のシートの件(8件、2016年)が1時間の入力でだけ違う形になる
- 昼夜は固定の時刻(6:00・18:00)で分けた。日の出・日の入り、季節、地域の違いは考慮していない
- 雨の日は日平均で決めたので、夕方の雨では翌日も雨の日になる。雨の直後(k = 3)の「3日」も日の単位
- 件数(119)と分割が段階29と違うので、段階29との比較は記述
- Dy_Npost の Holm 後 p = 0.0498 は境目。置換の回数を増やすと変わりうる
