# 土壌水分量(VWC)の時系列による多収・低収の分類: 結果の報告

- 作成日: 2026-10-31
- 図と表: `rocket/outputs/report_prof/`(`analysis/report_prof/make_report.py` で、段階6〜8の保存済みの結果から作成)

## 要点

1. **開花後60日間の VWC の1次差分(前日との差)を MiniRocket に入れると、AUC 0.605 で、偶然の水準を超えた**(置換検定 p = 0.035)。この解析は、探索の後に1つだけ事前に固定して行った確認用の解析である。
2. **VWC の要約統計・播種日・灌水の有無、VWC の生の値や z 正規化した値では、どれも偶然の水準だった**(AUC 0.43〜0.49)。手がかりは VWC の水準ではなく、日々の変化の並び方にあると考えられる。
3. **限界**: balanced accuracy(0.544)は偶然の水準を超えなかった。件数が82件と少なく、データを少し変えると結果が揺れる。

## 課題の設定

| 項目 | 内容 |
|---|---|
| ラベル | 市町村×年の中で収量の上位1/3を多収、下位1/3を低収(地域差・年の差を除いた相対評価) |
| データ | 2016〜2018年、82件(多収41・低収41)、21市町村 |
| 入力 | 開花日を0日目とし、0〜+59日の VWC(60点)。開花日が記録されていない22件は、播種日からの回帰式で推定(誤差の目安は平均4.4日) |
| 分類器 | MiniRocket(10,000カーネル)→ 標準化 → リッジ分類器(MiniRocket 原論文と同じ構成) |
| 評価 | 市町村単位で分けた5分割の交差検証を20回繰り返す(同じ市町村が学習とテストにまたがらない)。カーネルの乱数を10通り変えて平均 |
| 偶然の水準 | ラベルを市町村×年の中で並べ替えて同じ評価を繰り返し(1000回)、その分布の95%点を超えたら「偶然の水準を超えた」とする |

## 1. 主な結果

![図1](../../outputs/report_prof/fig1_null_main.png)

| 指標 | 結果 | 偶然の水準(95%点) | p |
|---|---|---|---|
| AUC | **0.605**(乱数10通りで 0.602〜0.607) | 0.595 | **0.035** |
| balanced accuracy | 0.544 | 0.562 | 0.131 |

- AUC は偶然の水準を超えた。ただし差は小さく、分類の精度として実用になる水準ではない。
- 多収・低収の判定(balanced accuracy)では、偶然の水準を超えなかった。

## 2. 比較: 時系列を使わない方法と、入力の形

![図2](../../outputs/report_prof/fig2_main_comparison.png)

| 方法 | AUC | balanced accuracy | AUC の偶然の水準 |
|---|---|---|---|
| VWC の要約統計(平均・SD など)+ ロジスティック回帰 | 0.428 | 0.491 | 0.601 |
| 播種日 + ロジスティック回帰 | 0.483 | 0.482 | 0.568 |
| 灌水の有無 + ロジスティック回帰 | 0.463 | 0.485 | 0.541 |
| MiniRocket・VWC の生の値 | 0.492 | 0.489 | 0.602 |
| MiniRocket・系列ごとに z 正規化 | 0.463 | 0.460 | 0.603 |
| **MiniRocket・1次差分** | **0.605** | **0.544** | **0.595** |

- 同じ分割で fold ごとの差を取ると、1次差分は生の値より AUC が **+0.113**、z 正規化より **+0.142** 高く、カーネルの乱数10通りすべてで同じ向きだった。
- z 正規化でもセンサーごとの水準差は消えるが、精度は上がらなかった。水準差を消すことより、**日々の変化(降雨後の上がり方や乾き方)を直接入れること**が効いていると考えられる。

## 3. 感度分析(MiniRocket・1次差分)

![図3](../../outputs/report_prof/fig3_sensitivity.png)

| データ | 件数 | AUC | 偶然の水準 | p |
|---|---|---|---|---|
| 全体(主な結果) | 82 | 0.605 | 0.595 | 0.035 |
| 開花日が実測の件のみ | 60 | 0.610 | 0.634 | 0.095 |
| 加古川(開花日がすべて推定)を除く | 76 | 0.618 | 0.603 | 0.030 |
| 灌水なしの件のみ | 70 | 0.587 | 0.621 | 0.124 |

- 推定開花日の件を除いても、AUC はほぼ同じ(0.610)。推定開花日が結果を作っているわけではない。ただし件数が減ると偶然の水準が上がるため、60件では超えなかった。
- 置換は、主な結果が1000回、感度分析は200回。

## 4. その他の確認(要約)

| 確認 | 結果 |
|---|---|
| 揃え方の比較(両方の窓を覆う77件、開花起点 vs 播種後日数) | AUC 0.541 vs 0.486。差は検出できなかった(+0.055)。**main から5件除いただけで 0.605 → 0.541 に下がっており、結果が件数に敏感** |
| ラベルを年の中だけで付けた場合(label_year、58件) | AUC 0.557(偶然の水準 0.680)。超えなかった |
| ROCKET(元の版)、1次差分 | 入力の尺度やプーリングを変えた4設定で AUC 0.48〜0.55。どれも偶然の水準 |

## 5. 限界と今後

- **効果は小さく、不安定**: AUC は偶然の水準をわずかに超えただけで、balanced accuracy では超えていない。77件の部分集合では超えなかった。
- **件数が少ない**: 82件・21市町村。2018年は数件しかない。
- **開花日の推定**: 22件(27%)は推定開花日で揃えている(感度分析では結果に大きな影響は見られなかった)。
- 今後の候補: 年・地域を増やしたデータでの確認、1次差分と相性のよい手法(MultiRocket など)との比較、気象データとの組み合わせ。
