## 判断が必要な点

1. **件数をどこまで許すか**
   - 窓を長くしたいなら、0〜+59(60日、82件)から (0, +63)(64日、80件)までは、ほとんど失わずに延ばせる。
   - 70日を超えるには、件数を72件以下まで下げる必要がある。
2. **開花前の期間を含めるか**
   - a > 0 にすると、最初に落ちるのは推定開花日の件(特に加古川)で、低収に偏っている。
   - 開花前を含む窓にすることは、事実上「加古川を除く」ことと同じになる。
   - 開花前を含む窓と含まない窓とでは、対象の集団が変わる。
3. **推定開花日の誤差**: 推定の件は pre が短い。推定の誤差(MAE 4.4日)の範囲で、a = 0〜5 付近の件数が変わりうる。段階3では、±2日のずれで加古川が2〜8件に変わった。
4. **長さが同じときの選び方**: 釣り合いの集団数を優先した。件数や推定開花日の少なさを優先する選び方もある。
5. **pre < 0 の10件**: 開花の後に観測が始まる。これらを入れたい場合は、窓の始まりを開花より後(a < 0)にする必要がある。今回の範囲(a = 0〜40)には含めていない。
