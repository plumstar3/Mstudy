## 目的

段階38(EXP-047)で、上昇量で割った NP_rise は偶然の水準(0.490)に下がった。ただし、上昇量が小さいイベントの後では値が極端になる。このため、下がった理由がノイズなのかを区別できなかった。

今回は割り算に頼らずに、次の問いを切り分ける。

- N_post の識別力は、雨での上昇量(反応の大きさ)の情報と同じものか
- それとも、別の減り方の情報を含むか

判定は全体 AUC で行う(D-007)。

## 方法(D-019 の要約)

| 名前 | 中身 |
|---|---|
| NP(基準) | 雨の直後の日は d = min(Δθ, 0)、ほかの日は0(段階38と同じ) |
| RISE | 雨の日は max(Δθ, 0)、ほかの日は0(段階27・38の P)。反応の大きさだけを持つ入力 |
| NP_resid | 雨の直後の各日について d − b_j × r(r はイベントの上昇量 θ(e) − θ(s−1)、j = 雨の後の何日目か)。b_j は、ラベルを使わずに解析集合の全イベントから、原点を通る最小二乗で求める(1組だけ) |
| NP_rise_robust | r ≥ 0.01 のイベントの後の日は d / r を [−1, 0] に切り詰めた値。r < 0.01 のイベントの後とほかの日は0 |

- 分類器と分割は段階38と同じ: MiniRocket(10,000、乱数0〜9)→ StandardScaler(with_mean=False)→ RidgeClassifierCV、`make_splits(y, muniCd, 5, 20, 0)`
- 置換検定: 市町村×年の中で各200回。主の4入力の p に Holm 補正をかけた
- 差: 市町村単位のクラスターブートストラップ2000回
- 記述のみ(置換なし):
  - b_j を各 fold の学習データだけで求めた NP_resid
  - NP と RISE の2チャンネル(MiniRocketMultivariate)

## 確認

### NP_resid の回帰(`resid_fit.csv`・`fig_scatter_resid.png`)

| j | b_j(120件) | 日数 | 原点を通る R² | d と r の Pearson | 残差と r の Pearson |
|---|---|---|---|---|---|
| 1 | −0.299 | 1230 | 0.60 | −0.59 | +0.17 |
| 2 | −0.216 | 992 | 0.57 | −0.53 | +0.25 |
| 3 | −0.140 | 754 | 0.49 | −0.43 | +0.27 |

- 108件で推定した値もほぼ同じ: b₁ −0.301、b₂ −0.214、b₃ −0.139
- fold ごとに推定した値の範囲: b₁ −0.329〜−0.266、b₂ −0.230〜−0.204、b₃ −0.146〜−0.131
- **残差と上昇量の相関は0にならなかった。** D-019 の確認の目安を満たしていない

  | 単位 | 減少 d と上昇量 | 残差と上昇量 |
  |---|---|---|
  | 日単位(Pearson) | −0.51 | +0.21 |
  | 圃場ごとの平均(Spearman) | NP −0.93 | −0.33 |
  | 圃場ごとの平均(層内) | −0.86 | −0.36 |

  理由は2つ。
  - 原点を通る回帰には切片が無い。Σ残差×r = 0 にはなるが、中心化した相関は0にならない
  - 散布図は扇形で、上昇量が大きいほど減少のばらつきが広がる。上昇量が大きくても減少がほぼ0の日が多く、直線では表せない
- 上昇量との相関は大きく減ったが(−0.93 → −0.33)、**NP_resid には上昇量の情報が一部残っている**
- 圃場ごとの平均で、NP_resid と NP の Spearman は 0.59、NP_resid と RISE は −0.38

### NP_rise_robust

- 上昇量 < 0.01 のイベントは 264 / 1257 個(21%)。その後の日 588 / 2976 日(20%)を0にした
- −1 に切り詰めた値は95個(残した日の4%)
- 圃場ごとの平均で、上昇量との相関は次のとおり

  | 入力 | Spearman | 層内 |
  |---|---|---|
  | NP_rise_robust | −0.38 | −0.41 |
  | 段階38の NP_rise | −0.18 | +0.04 |

  小さな上昇量のイベントを除いて値を切り詰めたことで、極端な値は減った。その代わり、上昇量との相関は段階38の NP_rise より強く残った

## 読み方(D-019 の事前の読み方に当てはめる)

- **読み方1(反応の大きさと同じ情報で説明できる): 当てはまらなかった。**
  - RISE は95%点を上回らず(0.547)、NP − RISE の区間は0より上(+0.106 [+0.039, +0.171])
  - 反応の大きさだけを持つ入力では、NP ほど見分けられない
- **読み方2(反応の大きさを取り除いても減り方に情報が残る): 主の120件では当てはまらなかった。**
  - NP_resid は 0.561 で、95%点(0.572)を上回らなかった(Holm 後 p 0.269)
  - 参考の108件では上回ったが(0.629、p = 0.015)、集合による違いが大きく、記述にとどめる
  - NP_resid には上昇量の情報が一部残っている(圃場ごとの平均で −0.33)。「反応の大きさを取り除いた」入力として不完全
- **読み方3(段階38の NP_rise の低下は主にノイズ): 当てはまらなかった。**
  - NP_rise_robust は 0.581(120件)・0.583(108件)で、どちらも95%点を上回らなかった
  - 108件で段階38の NP_rise(0.490)より +0.093 高い向きだが、区間は0を含む(差は検出できなかった)
  - ノイズを減らすと上がる向きはある。ただし、偶然の水準を上回るほどには戻らない
- **読み方4(NP には RISE を超える情報があるが、線形の残差では取り出せない): 当てはまった。**
  - NP − RISE の区間は0より上、NP_resid は偶然の水準だった
  - 散布図の扇形(上昇量が大きいほどばらつきが広がる)は、減少と上昇量の関係が線形ではないことと合う
- **読み方5: 当てはまらない。** 3つの入力の NP との差は、主の120件ではどれも区間が0より下だった(差が検出された)
- まとめると、**NP の識別力は、上昇量だけ(RISE)では説明できない。一方、上昇量の分を直線で引いた残りや、比にした値でも取り出せなかった。** NP は、上昇量と減り方の組み合わせ(たとえば「どの大きさの雨の後にどれだけ減るか」の非線形な関係)を使っている可能性がある(推測)。「排水の速さ」の解釈を支持する証拠は、今回も主の解析集合では得られなかった

## 注意

- **段階38の結果を見た後に決めた探索である。** N_post 自体も段階29で同じデータから見つけた仮説で、double dipping の問題が重なっている
- NP_resid は、D-019 で想定した「上昇量と相関しない残差」になっていない(日単位 +0.21、圃場ごとの平均 −0.33)。原点を通る直線という定義の限界で、NP_resid が偶然の水準だったことは「線形の残差では取り出せなかった」以上のことを言わない
- 参考の108件と主の120件で NP_resid の結果が分かれた(0.629 と 0.561)
  - 違いは、20202_2016(6件)・6203_2016(4件)・20202_2018 の2件の12件と、それに伴う分割の違い
  - b_j の違いは小さい(108件と120件で ±0.002 以内)
  - どちらが正しいとは言えない。12件で結果が動くほど、この件数の AUC は不安定である
- RISE は alpha が常に上限に張り付き、Ridge がほぼ切片だけのモデルになっていた。MiniRocket が RISE の系列から使える特徴を見つけられなかったことを示し、「上昇量に情報が無い」こととは別である
- NP + RISE の2チャンネルが NP より低かった(0.595)のは、特徴量が2倍になり、alpha の張り付きが増えた(0.91)ためかもしれない。置換検定はしておらず、記述である
- n = 120(主の集合)では差の区間が広い。読み方は「差の証拠があるか」の形で書いた
- 判定は全体 AUC で行い、地域内 W・地域間 B は出していない(D-007)

## まとめ

- 主の120件で、NP は 0.652(Holm 後 p 0.020)で95%点を上回った。RISE 0.547・NP_resid 0.561・NP_rise_robust 0.581 は上回らず、3つとも NP より低かった(区間は0より下)
- **NP − RISE は +0.106 [+0.039, +0.171]。N_post の識別力は、雨での上昇量(反応の大きさ)だけでは説明できない**
- 上昇量の分を直線で引いた NP_resid、ノイズを抑えた比 NP_rise_robust のどちらでも、NP の情報は取り出せなかった。事前の読み方4(「NP には RISE を超える情報があるが、線形の残差では取り出せない」)に当てはまる
- NP_rise_robust は段階38の NP_rise より高い向き(108件で +0.093、区間は0を含む)だったが、偶然の水準を上回らなかった。段階38の低下は、ノイズだけでは説明できない
- 参考の108件では NP_resid が95%点を上回った(0.629)が、主の120件では上回らず、集合で結果が変わった
