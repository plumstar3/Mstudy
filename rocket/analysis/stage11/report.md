## 設定

| ID | 内容 | 置換回数 |
|---|---|---|
| M | 1次差分 → MiniRocket(sktime 1.2.0、num_kernels=10000、乱数0〜9)→ StandardScaler(with_mean=False)→ RidgeClassifierCV(alphas = logspace(−3, 3, 10) × n_train)。段階6の実験Dと同じ構成 | 1000 |
| B1 | 窓内の生の VWC の要約統計(平均・標準偏差(ddof=1)・最小・最大)→ StandardScaler → LogisticRegression(C=1, max_iter=1000) | 1000 |
| B2 | 緯度・経度・播種日の通日(seed_doy)だけ → B1 と同じモデル(場所と時期だけ) | 1000 |
| S | 実測開花日の件だけで M・B1・B2(分割は作り直す) | 200 |

- 評価: `make_splits(y, groups=muniCd, n_splits=5, n_repeats=20, seed0=0)`。統計量は、乱数ごとの「20回の繰り返し平均」を10通りで平均した値。
- 置換検定: **ラベルを年の中で並べ替える**(置換 i の乱数は [0, i])。
- 判定: 平均が帰無分布の95%点を上回り、かつ同じデータの最良の基準線(B1・B2)を上回れば「当たっている」とする。主の指標は M の AUC。多重比較の補正はしない。

### 分割を固定した置換検定であること

- 年の中で並べ替えると、地域ごとのクラスの数が変わる。そのため、置換したラベルで StratifiedGroupKFold を作り直すと、分割は観測ラベルのときと同じにならない。
- この解析では特徴量を使い回すため、**観測ラベルで作った分割を、すべての置換で固定して使った**。帰無分布は「この分割のもとで、年の中のラベルの並びに意味が無い場合」の分布になる。
- 置換でテスト側が1クラスだけになった fold は、AUC を NaN として平均から除いた(既存の `summarize` と同じ)。観測ラベルでは、そのような fold は無かった(`n_auc_nan` = 0)。
- 帰無分布の平均は M で 0.498、B1・B2 で 0.50 前後なので、分割を固定したことによる平均の大きな偏りは見られない。

**開始時の確認**(すべて True)
1. Pipeline をそのまま回した結果と、特徴量を使い回した結果が一致する(M、乱数0、先頭10 fold)。
2. `run_stage6_local.perm_cached` と `run_stage6.perm_cached` の結果が完全に一致する(乱数0、置換20回、年の中で並べ替え。最大差 0)。

## 読み方

### 1. M の結果は土壌水分そのものの効果とは言えない

- label_year は年の中での相対評価で、地域差を含む。主データでは48地域のうち27地域が片方のクラスだけ(55件)で、「その地域が多収か低収か」がラベルの大部分を決めている。
- CV は地域単位(groups=muniCd)なので、同じ地域の圃場が学習とテストに分かれることは無い。ただし、近い地域の圃場どうしは雨の降り方などが似ている。M が拾っているのが「地域(気象)の違いが VWC に現れたもの」なのか、「圃場の土壌水分の違い」なのかは、この解析では分けられない。
- したがって M の AUC 0.635 は、**地域差も含めて、VWC の変動パターンから年内の多収/低収を当てられる**ことを示すもので、土壌水分の効果そのものの証拠ではない。

### 2. B2(場所と時期だけ)と M の差

- M は B2 を AUC で +0.231 上回り、差は10通りの乱数すべてで検出された(S でも同じ)。
- ただし **B2 の AUC 0.403 は偶然水準(0.5)を大きく下回る。** B2 の帰無分布(置換1000回)の中では下側約4%(最小 0.363、5%点 0.408)に位置する。置換したラベルでも0.36まで下がるので、この分割では、場所の特徴が逆向きに働きやすいと見られる。
  - 推測: 地域単位の分割では、テスト側の地域はその場所を一度も学習していない。片方のクラスだけの地域が多いため、テスト側の地域のクラスが学習側で少なくなり、近い場所の傾向が逆向きに当てはまりやすい。
- このため「M が B2 を上回った」ことは、**地域単位の分割のもとで、場所と時期の情報から得られる以上のものを、VWC から得ている**と読める。一方で、B2 が0.5を下回っているので、差の大きさ(+0.23)をそのまま「VWC の上乗せ分」と読むのは過大になる。0.5 を基準にすると M の上乗せは約 +0.13。
- 「場所の情報以上」とは、未知の地域に対して緯度・経度・播種日だけでは当てられないところを VWC で当てている、という意味になる。上の 1 のとおり、VWC が地域の気象を通じて情報を運んでいる可能性は残る。

### 3. 分割を固定した置換検定

- 上の「分割を固定した置換検定であること」のとおり。帰無分布の平均はどの設定も 0.50 前後で、固定による平均の偏りは見られない。ただし、置換ごとに分割を作り直した場合の分布と同じかは確かめていない。

### 4. 予測の開花日を含むことと S の結果

- 主データの162件のうち30件は、開花日が EXP-016 の予測。
- 実測開花日の件だけ(S、132件)でも、M は AUC 0.628(p = 0.030、95%点 0.597)・bacc 0.591(p = 0.025)で、帰無分布の95%点と最良の基準線(0.488)を上回った。
- 主データとの差は AUC で −0.007 と小さく、予測の開花日を含めたことが結果を左右しているようには見えない。置換回数は200回なので、p の精度は主データより粗い。

## まとめ

- label_year(162件)で、MiniRocket・1次差分(M)は AUC 0.635(p = 0.005)・bacc 0.593(p = 0.003)となり、帰無分布の95%点と最良の基準線を上回った(当たっている)。実測開花日の件だけでも同じ判定(AUC 0.628)。
- M は場所と時期だけの基準線(B2)を大きく上回った。ただし B2 は地域単位の分割で偶然水準を下回るので、差の大きさは割り引いて読む。VWC の要約統計(B1)との差は、主データの AUC では検出できなかった。
- label_year は地域差を含むので、これは土壌水分そのものの効果の証拠ではない。
- alpha は段階6と違って上限に張り付かなかった。

## 次の候補(ユーザーと相談する)

- 地域差を除く確認: 地域ごとの VWC の平均的な推移を引いてから1次差分にする(段階6の F2 と同じ考え方)、または片方のクラスしかない地域を除いた部分集合で評価する。
- B2 が0.5を下回る理由の確認: 地域ごとのクラス比と、テスト側の地域での予測の向きを集計する。
- 置換ごとに分割を作り直した置換検定(計算は重い)と、固定した場合の帰無分布の比較。
