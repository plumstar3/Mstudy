## 目的

段階29(旧データ)と段階31(v2 日平均)では、雨の直後の減少 N_post を MiniRocket に入力すると、全体 AUC が置換の95%点を上回った。一方、段階36では、圃場ごとの N_post が雨での上昇量 P と強く逆相関した(−0.79〜−0.92)。上昇量で割った減少率にすると、関連の向きは逆になった。

そこで、N_post の識別力がどちらから来ているのかを、尺度を合わせた入力で切り分ける。

- 「雨の後の排水の速さ」から来ているのか
- 「雨に対するセンサー・土壌の反応の大きさ」から来ているのか

元データの測定目的は「排水性に係るほ場間の差を、作土の土壌水分の差を調べて検知する」である。判定は全体 AUC で行う(D-007)。

## 方法(D-018 の要約)

**入力。** 長さ59(t = 1〜59)の1チャンネル。

| 名前 | 中身 |
|---|---|
| NP(基準) | 段階29の `components` と同じ。雨の日 Δθ > 0、k = 3。雨の直後の日は min(Δθ, 0)、ほかの日は0 |
| NP_rise | NP の各値を、その日が属する雨のイベントの上昇量 θ(e) − θ(s−1) で割る。上昇量 < 0.002 のイベントの後は0 |
| NP_fc | NP ÷ θ30(圃場ごとの定数) |
| NP_phi | NP ÷ φ、φ = 1 − bd/2.6 |

- 窓の最初の日の判定には、開花日より前の Δθ(t = −2〜0)を使った。観測が無い日は「雨の日なし」とした。前の Δθ が一部無い件は3、全部無い件は1
- イベントに割り当てた雨の直後の日数の合計は、段階29の定義の雨の直後の日数と全件で一致した

**分類器。** 段階29と同じ構成にした。
- MiniRocket(10,000、カーネルの乱数 0〜9)→ StandardScaler(with_mean=False)→ RidgeClassifierCV(alphas = logspace(−3, 3, 10) × n_train)
- 分割は `make_splits(y, muniCd, 5, 20, 0)`。学習とテストで市町村が重ならないことを確認した
- 段階13の prechecks(Pipeline との一致、置換で分割が変わらないこと、まとめて解いた置換 = sklearn)はすべて True だった

**基準線。** StandardScaler → LogisticRegression(C = 1)。説明変数は bd / θ30 / a30 / bd + θ30 の4通りで、主の集合と同じ分割を使った。

**置換検定。**
- 市町村×年の中でラベルを並べ替えた。回数は MiniRocket が各200回(帰無分布は乱数10通りの平均)、基準線が各1000回
- 主の4入力の p に Holm 補正をかけた

**差。**
- 市町村単位のクラスターブートストラップを2000回行った(段階27・29と同じ)
- 基準線のスコアは乱数によらないので、10通り分を同じ値で並べて重みをそろえた

  | 量 | 変動係数(全体) | 変動係数(層内の中央値) |

  上昇量は θ30・φ とも弱い相関しかない(−0.35・−0.09)
- 上昇量で割った NP_rise だけが、上昇量との相関を消した(−0.03)。段階36の rate_k3|θ0 とは Spearman 0.95、NP と段階36の N_post_k3|θ0 とは 0.998 だった。違いは、t = −2・−1 の雨の日を見るかどうか
- 上昇量 < 0.002 のイベントは80個あった。その後の雨の直後の176日(全2976日の6%)を、NP_rise で0にした
- NP_rise には、1日で上昇量より大きく減る値(< −1)が296個・92件ある(最小 −28.9)。上昇量が小さいイベントの後で大きくなる

## 読み方(D-018 の事前の読み方に当てはめる)

- **読み方1(物性で割っても情報が残る): 支持されなかった。**
  - NP_phi は95%点を上回ったが、NP との差の区間が0を含まない(わずかに下)
  - NP_fc は95%点を上回らなかった
  - φ で割っても上昇量との相関は −0.90 のままで(結果1)、NP_phi は NP とほぼ同じ入力である。NP_phi が残ったことは、「反応の大きさをならしても情報が残る」証拠にはならない
- **読み方2(反応の大きさによるものが大きい): NP_rise では当てはまった。NP_fc は境目。**
  - 上昇量で割って反応の大きさを取り除いた NP_rise は偶然の水準(0.490)に下がり、NP との差の区間は0より下だった
  - NP_fc も区間が0より下で、AUC は95%点ちょうど
- **読み方3(NP_rise だけが下がり、NP_fc・NP_phi は残る): 一部だけ当てはまる。**
  - NP_phi は残り、NP_fc は残らなかった
  - ただし今回は「土の物性による尺度合わせ」が、ほとんど尺度を合わせていない(上昇量との相関が変わらない)。そのため、「データから作る尺度合わせと物性による尺度合わせは別のものを見ている」と言える状態ではない
- **読み方4(基準線が95%点を上回る): 当てはまらなかった。**
  - 土の物性だけでは、多収・低収を偶然以上に見分けられなかった。bd が境目(p = 0.063)
- まとめると、**N_post の識別力は、上昇量で取り除ける「雨への反応の大きさ」と切り離せなかった**。今回のデータでは、「排水の速さ」に情報がある、という解釈を支持する結果は得られなかった

## 注意

- **NP_rise が下がった理由は、反応の大きさを取り除いたことだけとは限らない。**
  - 上昇量で割ると、小さな上昇量のイベントの後の値が極端に大きくなる(< −1 が296個、最小 −28.9)
  - 上昇量 < 0.002 のイベントの後の6%の日は0にした
  - alpha が上限に張り付く割合も 0.80 に増えた
  - 割ることで入るノイズや値の大きさの偏りが AUC を下げた可能性があり、この実験では区別できない
- **物性の尺度合わせは弱い。**
  - θ30・φ は圃場間の違いが小さい(層内の変動係数 0.12・0.06)
  - センサーと深さが違い、播種後・中耕培土前に1回(1〜4コア)測っただけである
  - センサーの位置での反応の大きさを、物性では表せていない
  - 「物性で割っても情報が残る/残らない」から、排水の速さについて強いことは言えない
- 物性がそろう件に絞った108件では、θ30 が測られていない 20202_2016(6件)と 6203_2016(4件)が外れている。この10件が外れた集合での結果である(参考の120件の NP は 0.652)
- MiniRocket は入力の値の大きさに対して不変ではない(バイアスは学習データの畳み込みの値の分位点)。定数で割ると特徴量が変わる
- N_post は段階29で同じデータから見つけた仮説である。double dipping の問題は残る。本研究は探索的な解析として進めている
- n = 108(20市町村)では、入力どうしの差が0.05程度でも区間が0を含みやすい。基準線との差はどれも検出できなかったが、「差がない」という意味ではない
- 判定は全体 AUC で行い、地域内 W・地域間 B は出していない(D-007)。`per_seed.csv` に W・B の値は残っているが、記述にも使っていない

## まとめ

- 元Excel から土壌物性の表を作った。主ラベル120件のうち bd と θ30 の両方があるのは108件で、事前の目安どおりだった。2列以上ある列は圃場内のコアの反復と判断した。2016 G1〜G12 の θ30 の列には、三相分布が入っていた
- 108件で、NP(0.673)と NP_phi(0.649)は Holm 後も95%点を上回った。NP_fc(0.589、p = 0.055)と NP_rise(0.490)は上回らなかった。**尺度合わせ版の3つとも、NP より低かった**(差 −0.02 / −0.08 / −0.18、区間はどれも0より下)
- **土の物性(θ30・φ)で割っても、N_post と上昇量の相関はほとんど減らない**(−0.91 → −0.90)。物性による尺度合わせでは、反応の大きさを取り除けていない
- **反応の大きさを取り除いた NP_rise は、偶然の水準に下がった**。N_post の識別力は「雨への反応の大きさ」と切り離せず、「排水の速さ」に情報があるという解釈は今回のデータでは支持されなかった(割り算で入るノイズの影響は区別できない)
- 土の物性だけの基準線は、どれも偶然の水準を上回らなかった(bd 0.586、p = 0.063 が最高)

## 次の候補

- 上昇量を割るのではなく、共変量として扱う
