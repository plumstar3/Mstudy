## 目的

分類器を使わずに、土壌水分の動態と収量の関連を検定する。段階32〜35では、検定の種類やパラメータを変えた試行が累計456個あり、Holm 補正後に残ったものは0個だった。今回は次の2点を変えた。

1. **「複数の組を試して最良を選ぶ」手順全体を、置換の中で毎回やり直す**(Westfall–Young の single-step max-T)。これで、最良の組を選んでも有効な p(選択込みの p)が出る
2. **検出力を上げる**。目的変数に連続値の相対収量 y_rel を使い(中央の件も使える)、特徴量を雨のイベントに揃えた圃場ごとのスカラーにする

## データ

| 項目 | 値 |
|---|---|
| データ | `soilmoisture_timeseries_fixed.csv`(D-013)、515 を除く。窓は flower_date を0日目とした 0〜+59 日、収穫日より後は使わない、60日そろう件だけ |
| 層 | 市町村×年。`label_muniyear_median` が付く集団(4圃場以上、29集団)に限る |
| Y1(相対収量、主) | y_rel = log(収量 / 市町村×年の平均)。平均は集団の全件(窓の外も含む)。**123件・27集団**(候補151件のうち28件は窓がそろわず外した)。主ラベルの120件 + 中央の空欄3件 |
| Y2(主ラベル、比較用) | `label_muniyear_median`、120件(多収61/低収59)、層内のペア144組 |
| 年ごと | 2016 81件・18集団 / 2017 34件・7集団 / 2018 8件・2集団 |
| 集団の大きさ | 2件が2集団、3件が1集団、4件以上が24集団。S1 に使うのは3件以上の25集団・119件 |
| 雨のイベント(1圃場あたり) | θ0 平均 10.5回(6〜15)、θ2 9.9回(5〜15)、θ5 9.1回(4〜14)。イベントの無い圃場は0、NaN の特徴量は0 |

## 方法(D-016 の要約)

- 雨の日: θ0 = Δθ > 0(段階29の主)、θ2 = Δθ ≥ 0.002、θ5 = Δθ ≥ 0.005。窓の0〜59日目で判定(開花日より前の雨は見ない)。雨のイベント = 雨の日が続く区間。APCPRA による定義は見送った(VWC で雨の日でない日の56%が APCPRA ≥ 1 mm で、使うには新しいしきい値を後から決める必要があるため)
- 特徴量(**減少は負の値のまま。値が小さいほど大きく減る**):

| 記号 | 中身 |
|---|---|
| F1 N_post(k = 1, 2, 3, 5) | イベントの翌日から k 日の min(Δθ, 0) の平均(次の雨の前と窓の終わりで打ち切り)をイベント間で平均 |
| F2 減少率(k = 3) | F1(k = 3)÷ そのイベントの上昇量(上昇量 0.002 未満のイベントは使わない)。尺度を消した版 |
| F3 N_dry | 雨の日でも雨の後3日以内でもない日の min(Δθ, 0) の平均 |
| F4 N | 59日の min(Δθ, 0) の平均 |
| F5 イベント数 | 雨の日の区間の数 |
| F6 P(対照) | 59日の max(Δθ, 0) の平均。族の外 |

- 統計量(すべて層の中だけで比べる、両側):
  - S1(Y1): 層ごとの Spearman ρ の件数重み付き平均(3件以上の層)
  - S2(Y1): 層ごとの正規化した順位 u = (rank − 0.5)/n(同点は平均順位)を特徴量と y_rel の両方に作り、全件で Pearson 相関
  - S3(Y2): 層内 AUC
- 族: **Y1 の族 = 22特徴量 × {S1, S2} = 44組(主の判定)**、Y2 の族 = 22組、対照 P = 3組(族の外)。合計69組
- 層内置換10,000回(置換 i は `default_rng([0, i])`)。圃場と (y_rel、ラベル) の対応を層の中で同時に並べ替えた。各組を置換の帰無分布の平均・標準偏差で z にし、選択込みの p = (#{置換の族内最大 |z| ≥ 実データの |z|} + 1) / 10,001
- **判定(主): Y1 の族で選択込みの p < 0.05 の組があるか**

**確認**: 置換が層の中だけで動き、各層のラベルの数が保たれることを確かめた。S1 は scipy の `spearmanr` で層ごとに計算し直した値と、S3 はペアを1つずつ数えた値と一致した(N_post_k3|θ0 で確認)。

## 結果

### 判定: Y1 の族の選択込みの p は最小 0.948 で、関連は検出されなかった

| 族 | 組 | 置換の最大 \|z\| の95%点 | 実データの最大 \|z\| | **選択込みの p の最小** | 補正前 p < 0.05 | Holm 後 p < 0.05 |
|---|---|---|---|---|---|---|
| **Y1(相対収量、主)** | 44 | 2.89 | 1.14 | **0.948** | 0 | 0 |
| Y2(主ラベル) | 22 | 2.84 | 1.31 | 0.827 | 0 | 0 |

**事前の基準では、Y1 の族のどの組でも、土壌水分の特徴量と相対収量の層内の関連は検出されなかった。** 補正前の p でも 0.05 を下回る組は1つも無い(最小 0.257)。実データの最大 |z| 1.14 は、置換の最大 |z| の分布(95%点 2.89)のほぼ下端にある(`fig_null_max.png`)。選択込みの p が1に近いのは、44組を同時に見れば偶然でもこの程度の |z| が出るのが普通だからで、補正の結果として特別なことではない。

### 向きの数(記述)

| 族 | 組 | z > 0 | z < 0 |
|---|---|---|---|
| Y1 | 44 | 14 | 30 |
| Y2 | 22 | 4 | 18 |

特徴量ごとでは、F3 N_dry と F4 N はすべて負、F1 N_post は Y1 で 24組中15組が負(k = 1 は6組すべて正、k = 3 は6組すべて負、k = 2・5 は6組中4・5組が負。Y2 では k = 1 の1組だけが正)、**尺度を消した F2 減少率はほとんどが正**(Y1 6組中4組、Y2 3組中3組)だった(`sign_by_feature.csv`)。

**この割合は独立な証拠の数ではない。** 組どうしの相関が強い: 同じ特徴量の雨の定義違い(たとえば N_post_k3 の θ0・θ2・θ5 の間の Spearman 相関は 0.98〜0.99)、同じ特徴量の S1 と S2(ほぼ同じ値)、N_post と N(0.92〜0.94)。44組で30組が負でも、実質的には少数の独立な情報の向きでしかない。

### 読み方(記述、推測を含む)

- 負の z(N_post・N_dry・N が小さい = 大きく減る圃場ほど、相対収量が高い / 多収)は、段階26の「多収は普段の日の減り方がやや大きい」と同じ向き。ただし大きさは小さく、検定では検出できない
- **N_post は対照 P と強く逆相関する**(全件の Spearman で −0.79〜−0.92、N と P は −0.96)。雨で大きく上がる圃場は、その後も大きく下がる。対照 P の z は +1(上がり方が大きい圃場ほど相対収量が高い向き)で、N_post の z −1 とちょうど鏡写しになっている。**上昇量で割った F2 減少率では向きが正に変わる**。これらから、N_post などの負の向きは「雨の後の排水の速さ」ではなく「センサー・土壌の反応の大きさ」の違いを反映している可能性がある(推測)

## 注意

- **特徴量の候補(N_post など)は、段階29で同じデータから見つけた仮説である。** この点で double dipping の問題は残る。選択込みの p は、今回試した69組の中での選択だけを補正するもので、段階26〜35の探索(何を候補にするかを決めた過程)は補正していない。今回は検出されなかったので結論の向きは変わらないが、もし検出されていても、独立なデータでの確認が必要だった
- **有意差が無くても、関連が無いことの証拠ではない。** 今の件数では検出力が足りない可能性がある(D-007)。最良の組の層内 ρ の95%区間は [−0.32, +0.10] で、中程度の関連(|ρ| ≈ 0.3)も否定できない。S1 は25集団・119件、S3 は144ペアしかない
- 選択込みの p は族の中の多重性を厳しく(強い FWER で)制御する。44組の中に1つだけ本当に関連のある組があっても、その |z| が 2.89 を超えなければ検出できない。相関の強い組が多いので、44個の独立な検定に Bonferroni をかけるよりは緩い(95%点 2.89 は Bonferroni の 3.25 より低い)
- 雨の日は窓の0〜59日目だけで判定したので、段階29とは窓の最初の数日の扱いが違う(開花日より前の雨は見ていない)
- 開花日の前日の観測が無い2件は、0日目を雨の日なしとして扱った

## まとめ

- **雨のイベントに揃えた22個の特徴量と相対収量の層内の関連は、選択込みの置換検定(max-T)で検出されなかった**(Y1 の族の選択込みの p の最小 0.948、補正前でも最小 0.257)。主ラベル(Y2)でも同じ(最小 0.827)
- 連続値の目的変数・層内の順位相関・スカラー特徴量にして検出力を上げようとしたが、段階32〜35と同じく差は出なかった。対照 P は族の最良の組と同じ大きさ
- 向きは「大きく減る圃場ほど相対収量が高い」に偏ったが(Y1 44組中30組、独立な証拠ではない)、N_post は上昇量 P と強く逆相関し、尺度を消すと向きが変わるので、反応の大きさの違いを見ている可能性がある(推測)
