## 目的

主の設定 M_diff(1次差分 → MiniRocket、label_muniyear_median 123件)で精度が出る理由を、入力の形を変えて切り分ける。

- **Q1**: 1次差分が効いたのは、センサー・圃場ごとの水準のズレが消えたからか、日々の変化そのものに情報があるからか
- **Q2**: 水分が増える動き(降雨・灌水への応答)と減る動き(乾燥・蒸発散)の、どちらに多収・低収の情報があるか。段階26の推測「多収は普段の日の減り方がやや大きい」を確かめる

## 設定

θ(t) は窓内の生の VWC(t = 0…59)、Δθ(t) = θ(t) − θ(t−1)。長さはすべて59点。

| 記号 | 入力 | 定義 | 変換器 |
|---|---|---|---|
| D | 1次差分 | Δθ(t) | 段階13の M(保存済み、置換1000回) |
| A | 開花起点の相対値 | θ(t) − θ(0)、t = 1…59 | MiniRocket(10000) |
| P | 正の差分(増える動き) | max(Δθ, 0) | MiniRocket(10000) |
| N | 負の差分(減る動き) | min(Δθ, 0) | MiniRocket(10000) |
| PN | 正負の2チャンネル | [P, N] | MiniRocketMultivariate(10000、特徴量9,996で D と同じ数) |

| 項目 | 値 |
|---|---|
| 分類器 | StandardScaler(with_mean=False)→ RidgeClassifierCV(logspace(−3, 3, 10) × n_train)、乱数0〜9 |

| 多重比較 | A・P・N・PN の4つの全体 AUC の p に Holm 補正を併記 |

**判定(事前に固定)**
- Q1: A > 95%点 かつ D − A の区間が0を含む → 1次差分の効果の大部分は水準のズレの除去。D − A の区間が0より上 → 変化そのものに水準除去以上の情報がある
- Q2: N > 95%点 かつ P ≦ 95%点 → 減る動き(乾燥)に情報がある。その逆 → 増える動きに情報がある。PN − D の区間が0より上 → 正負を分ける形を次の段階の候補に(採用は別途相談)

開始時の確認(すべて True): EXP-036 が未使用、件数123件・窓60点・分割が段階13と同じ、入力の定義(P + N = Δθ、P ≧ 0、N ≦ 0、A の1次差分 = Δθ、PN = [P, N])、D の再計算(乱数0、先頭10 fold)が段階13と一致、Pipeline と特徴量の使い回しが一致(A・PN)、まとめて解いた置換 = sklearn(P は段階13の prechecks、PN は置換20回)、置換5回で分割が変わらない。40の (入力, 乱数) すべてで fold の AUC・bacc が sklearn と一致し、W+B+X = fold の AUC。

ゼロの割合: P 0.691(69%の日は増えていない)、N 0.312、Δθ がちょうど0 は 0.003。

## 判定

- **Q1**: A は95%点に届かず(0.535)、D − A は +0.071 [+0.052, +0.114] で0より上。**変化そのものに、水準のズレの除去以上の情報がある**
- **Q2**: N は95%点を上回り(0.626 > 0.598、p = 0.020)、P は上回らない(0.577 < 0.597)。事前の基準では **減る動き(乾燥)に情報がある(段階26の推測を支持)**。ただし Holm 補正後の N の p は 0.080 で、4入力の多重比較を考えると5%を上回る。また N − D の区間は0を含み、N が D より良いとは言えない
- **PN − D** は +0.006 [−0.024, +0.027] で0を含む。**正負を分ける形は次の段階の候補にしない**

## 考察

### Q1: 水準のズレか、変化か
- 開花起点の相対値 A は、各圃場の水準(θ(0))を引いて消し、累積の軌跡を残した入力である。A(0.535)は生の値(0.506)より少し高いが偶然の水準で、1次差分(0.607)には届かない。1次差分の効果は、水準をそろえただけでは得られず、**日々の変化として表したことに意味がある**
- ただし、sktime の MiniRocket はゼロパディングのため平行移動に不変でない(EXP-009)。A は t = 1 の値が0付近から始まる累積の曲線で、生の値とも1次差分とも形が違う。A と生の値の違い、A と D の違いには、この性質の影響も含まれうる

### Q2: 増える動きか、減る動きか
- 減る動きだけの N は、全体 0.626 で D(0.607)と同じくらい当たり、増える動きだけの P(0.577)は偶然の水準だった。**多収・低収の情報は、主に水分が減る日の動きにある**と読める。段階26の「多収は普段の日の減り方がやや大きい」と同じ向き(推測の裏付けの一つ。作物の水の使い方を反映している可能性は推測のまま)
- 注意: N は増えた日を0にした系列なので、「いつ増えたか(雨の日の位置)」の情報も0の並びとして残る。P も同様に減った日の位置を残す。N の結果が「乾燥の速さそのもの」だけによるとは限らない
- **N では地域内 W も 0.613 で95%点(0.600)を上回った(p = 0.040)**。主ラベルで W が95%点を上回った例は、これまでの記録では相対収量の回帰 R_all(段階20、0.602 > 0.596)のほかに見当たらない。ただし W は判定に使わない記述で、置換は200回、4入力を見た中の1つなので、偶然の可能性を残す。確かめるなら判定を事前に決めて別の段階で行う
- N だけ alpha の張り付きが46%と低い(D 81%、P 98%)。N では、強い正則化をかけなくても使える特徴量が多い、と考えられる(推測)
- 正負を分けて2チャンネルにした PN(0.613)は D と変わらない。負の部分の情報は、1次差分のままでも MiniRocket が使えていると考えられる。それでも N の W(0.613)が D・PN(0.536・0.562)より高い理由は分からない(記述)
