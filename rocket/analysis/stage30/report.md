# 段階30: 段階27・29の設定どうしの AUC の差の、Holm 補正前の両側 p 値(EXP-039)

- 日付: 2026-11-19
- スクリプト: `analysis/stage30/run_stage30.py`(`rocket\venv_rocket\Scripts\python rocket\analysis\stage30\run_stage30.py`、1秒)
- 出力: `outputs/stage30/`(`pairwise_p.csv`, `run_log.txt`)
- **モデルの学習・置換検定・ブートストラップの計算は回し直していない。** 段階27・29の保存済みの結果だけを使った。段階27・29の入力・出力・スクリプト、`src/` は変更していない
- データ: 段階27・29と同じ旧日平均(123件)の結果(段階29はユーザーの決定により旧データの結果として記録。D-008 の新しいデータでの確認は別の段階で相談する)

## 目的

段階27(EXP-036)と段階29(EXP-038)の設定どうしの AUC の差に、Holm 補正前の両側 p 値を付ける。

## 方法

| 項目 | 内容 |
|---|---|
| ブートストラップの値 | `outputs/stage27/bootstrap_auc.csv`(D・A・P・N・PN)と `outputs/stage29/bootstrap_auc.csv`(N・R・N_dry・N_post)。市町村単位の対応のあるクラスターブートストラップ(段階14と同じ重み付け、乱数 `default_rng(0)`)、B = 2000 |
| 差の取り方 | 同じリサンプル番号(`boot`)どうしの差。どちらのファイルにも番号が対応づけて保存されていたので、ブートストラップの計算し直しは不要だった。段階29の N の値は、段階27の N と2000リサンプルすべてで一致した(両段階は同じリサンプル) |
| 点推定 | fold の AUC の平均の差(段階27・29の report と同じ)。D・P・N は `outputs/stage27/folds.csv`、R・N_dry・N_post は `outputs/stage29/folds.csv`(どれも乱数10 × 繰り返し20 × 5 fold = 1000 fold) |
| 両側 p | p = min(1, 2 × (1 + min(#{差 ≤ 0}, #{差 ≥ 0})) / (B + 1))。B = 2000 では、差がすべて同じ符号のときの最小値が 2/2001 ≈ 0.0010 |
| 95%区間 | パーセンタイル法(2.5%点・97.5%点) |

**差の向き**: 依頼の向きにそろえた。report と向きが逆の4組は符号を反転した。

| この段階の組 | 元の report の組 |
|---|---|
| D − P | P − D(段階27) |
| D − N | N − D(段階27) |
| P − N | N − P(段階28 部分A) |
| N − N_post | N_post − N(段階29) |

N_dry − N_post、R − N、N_dry − N は report と同じ向き。

**開始時の確認**: 7組の点推定と95%区間が、元の report の値(向きをそろえて符号を反転したもの)と、小数第3位の丸めの幅(±0.0005)で一致した(7組すべて True)。
- 最初の確認では、段階29の3組(N_post − N、R − N、N_dry − N)の点推定が report と0.001ずれていた。原因は段階29の report の二重の丸め(ログに小数第4位で出た値をさらに小数第3位に丸めた)だった。計算した値は `outputs/stage29/diffs.csv` と浮動小数の桁まで一致していた。ユーザーの確認後、段階29の report を正しい値(+0.041、−0.197、−0.152)に直してから確認をやり直した

## 結果

| 段階 | 組 | 点推定 | 95%区間 | p(補正前、両側) | 差 ≤ 0 の数 | 差 ≥ 0 の数 | 読み |
|---|---|---|---|---|---|---|---|
| 27 | D − P | +0.029 | [−0.016, +0.088] | 0.178 | 177 | 1823 | 差は検出できない |
| 27 | D − N | −0.019 | [−0.074, +0.040] | 0.559 | 1442 | 558 | 差は検出できない |
| 27 | P − N(探索的) | −0.048 | [−0.140, +0.031] | 0.228 | 1773 | 227 | 差は検出できない |
| 29 | N_dry − N_post | −0.194 | [−0.301, −0.088] | **0.001** | 2000 | 0 | 差あり(Holm 補正前) |
| 29 | N − N_post | −0.041 | [−0.080, +0.000] | 0.056 | 1945 | 55 | 差は検出できない(境目) |
| 29 | R − N | −0.197 | [−0.329, −0.051] | **0.010** | 1991 | 9 | 差あり(Holm 補正前) |
| 29 | N_dry − N | −0.152 | [−0.257, −0.050] | **0.002** | 1999 | 1 | 差あり(Holm 補正前) |

(B = 2000)

## 読み方

- **補正前の p である。** 組が7つあるので、多重比較の補正(Holm など)をかけると結論が変わる組がありうる。今回は Holm 補正を計算していない
- **段階27の3組**: どれも差は検出できない。1次差分 D・正の差分 P・負の差分 N の間で、全体 AUC の違いは確かめられない。「同じ」という意味ではない
- **P − N** は、段階27の結果を見てから決めた事後の比較なので、探索的な結果として扱う
- **段階29**: 無降雨日の減少 N_dry は、雨の直後の減少 N_post より低く(p = 0.001。2000リサンプルすべてで差が負で、B = 2000 での最小の p)、N より低い(p = 0.002)。雨の日の位置 R も N より低い(p = 0.010)
- **N − N_post(境目)**: 点推定 −0.041、95%区間 [−0.080, +0.000](上端は +0.00011)、p = 0.056。差 ≥ 0 のリサンプルは2000回のうち55回(2.75%)で、5%の基準のすぐ外にある。N_post が N より高い向きだが、補正前でも差があるとは言えない。p も区間の上端もリサンプルの回数と乱数に左右されうる値で、境目の結果として読む
