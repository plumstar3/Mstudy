# データの問題点と対応

## 1. 播種日・収穫日の補完(2026-11-05 確認・対応)

### 経緯

リポジトリルートの `data/processed/FieldData_fieldid.db` は、`data/raw/FieldData.db` に field_id を付けたうえで、次の修正を加えたもの。

| 修正 | スクリプト | 件数 |
|---|---|---|
| 播種日の欠損を近傍圃場から補完 | `impute_growing_dates.py --write-db` | 26 |
| 収穫日の欠損を近傍圃場から補完 | `impute_growing_dates.py --write-db`、`fix_field5_harvest.py` | 92 + 1 |
| A4・2016 の収穫日(2016-07-25)を開花日の誤入力として `flower_date` に移す | `fix_field5_harvest.py` | 1 |
| 株間 `between_stocks` の文字化けを 12.5 に修正 | 不明 | 44 |

補完は、同じ年の100 km 以内の近傍3圃場の通日の中央値。開花日推定で補完値を使うと、推定の入力に推定値が混ざる。

### 対応

- ルートの `add_raw_growing_dates.py` で、`Questionaire` に **`seed_date_raw` / `harvest_date_raw`** を追加した。中身は元の `FieldData.db` の値(補完前)。既存の `seed_date` / `harvest_date`(補完済み)は残している。作業前のバックアップは `data/processed/FieldData_fieldid.db.bak_before_rawdates`
- A4・2016 は開花日への移し替えを残し、`harvest_date_raw` を NULL にした
- 確認: A4・2016 以外は2列とも元の `FieldData.db` と一致。値がある行は既存列とも一致
- このDBを `rocket/data/raw/FieldData_fieldid.db` にコピーし、以後こちらを使う

| 列 | NULL | うち補完済み列には値がある |
|---|---|---|
| `seed_date_raw` | 117 | 26 |
| `harvest_date_raw` | 183 | 93 |

**開花日推定には `seed_date_raw` / `harvest_date_raw` を使う。**

参考: `data/processed/FieldData_fieldid_raw.db` は元の `FieldData.db` に field_id を付けただけのもの(ルートの `build_fielddata_fieldid_raw.py`)。A4・2016 も元のまま(収穫日が 7/25)なので注意。

## 5. 土壌物性(仮比重・吸引圧の体積含水率)の元データ(2026-11-28 確認、段階38)

- **複数の列がある理由**: 見出しは1列目にだけあり、残りの列は見出しの無い続きの列。実施要領(`大豆の多収阻害要因実態調査実施要領2017年版（完成版).docx`)に「は種後一雨当たった後、中耕培土前に深さ5〜10cm部からコア2個採取して測定」、`2016年度版_物理性調査位置.pptx` に圃場内の2か所(入水口側・排水口側など)で採取とあるので、**圃場内の反復(コア)**と判断した。列どうしの相関は bd 0.91〜0.93、θ30 0.81〜0.93。3・4列目があるのは一部の県だけ(2016 G・H、2017 B・H)。値がある列の平均を使った
- 採取の深さ: 実施要領では深さ5〜10cm(作土の中央部)、pptx では畝頂から耕盤までの真ん中、100cc 金属円筒。**土壌水分センサー(スキ床の約3cm上)とは深さが違う**
- **2016年 G1〜G12(長野、20202_2016)は θ30・θ5 の列に三相分布が入っている**(47列は空欄、48〜50列が気相・液相・固相の %、G1 だけ「気相48.4」のように文字付き)。θ30・θ5 は欠測とした。bd(44〜46列)は3反復の値として使う
- 2018年の18列は、G01〜G10 では pF1.5 の三相分布の試料の仮比重(41列と同じ値)で、反復ではない(17列との相関 0.03)。bd は17列だけを使った。このため G06・G07(主ラベルの件)は bd が欠測。B07・B08 では18・20・22列が反復らしい値だが、主ラベルの件ではない
- 2018年 I01・I07 は θ30・θ5 が割合(0.56〜0.68)で書かれている(ほかは %)。1.5 未満の値は割合とみなして100で割らなかった
- 数値でない記入は欠測にした:「測定せず」(2016・2017 C 系列、2018 J01)、「－」「-」「（未実施）」(θ5)、2018 P04〜P12 の「Bは共通」「Cは共通」(別のサンプルと共通という注記。主ラベルの件ではない)、2016 の作土深「10〜11」などの範囲の記入と「収穫後のため不明」(作土深は段階38では使っていない)
- 主ラベル120件で各項目がそろう件数: bd 118、θ30 110、θ5 79、作土深 117、土粒子密度 25。**bd と θ30 の両方は108件**(外れるのは 20202_2016 の6件(θ30 が三相分布)・6203_2016 の4件(C5〜C8、測定せず)・20202_2018 の2件(G06・G07、bd 欠測))

- 層(市町村×年)内の分散の割合は bd 0.36・θ30 0.36・φ 0.36・a30 0.37。物性の違いの大半は集団の間にある
